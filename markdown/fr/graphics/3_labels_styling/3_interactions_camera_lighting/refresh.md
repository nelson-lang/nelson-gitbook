# refresh

Rafraîchir la figure courante.

## 📝 Syntaxe

- refresh()
- refresh(F)

## 📥 Argument d'entrée

- F - Objet graphique figure.

## 📄 Description

<b>refresh</b> efface et redessine la figure courante.

<b>refresh(F)</b> redessine la figure identifiée par <b>F</b>.
