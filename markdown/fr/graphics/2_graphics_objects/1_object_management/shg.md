# shg

Affiche la fenêtre graphique courante.

## 📝 Syntaxe

- shg
- shg()

## 📄 Description


<b>shg</b> met la figure courante au premier plan, en créant une si aucune n'existe. C'est équivalent à <b>figure(gcf)</b>.

## 💡 Exemple



```matlab
f = figure();
plot(1:10);
shg
```
