# scatter properties

Proprietes de l'objet graphique scatter.

## 📄 Description

Cette page documente les proprietes visibles retournees par <b>properties</b> pour un objet graphique <b>scatter</b>.

## 💡 Exemple

Creer l'objet graphique et lister ses proprietes.

```matlab
f = figure('Visible', 'off');
ax = axes('Parent', f);
h = scatter(ax, 1:3, [2 1 3]);
names = properties(h);
close(f)
```
