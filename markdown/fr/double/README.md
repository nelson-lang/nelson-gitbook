# Double


    
Le module Type Double fournit des outils pour gerer les valeurs numeriques en precision double dans Nelson.

    
Il convertit les valeurs en double precision et donne acces aux principales limites numeriques des nombres a virgule flottante.

  

## Functions

- [double](double.md) - Convertit une variable au type double précision.
- [flintmax](flintmax.md) - Plus grand entier consécutif représentable en virgule flottante.
- [realmax](realmax.md) - Plus grand nombre flottant positif.
- [realmin](realmin.md) - Plus petit nombre flottant positif.
