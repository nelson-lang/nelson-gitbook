# getlanguage

Renvoie la langue courante dans Nelson.

## 📝 Syntaxe

- lang = getlanguage()

## 📤 Argument de sortie

- lang - une chaîne : langue courante utilisée dans Nelson.

## 📄 Description


<b>getlanguage</b> renvoie la langue courante utilisée dans Nelson.

## 💡 Exemple



```matlab
l = getlanguage()
```
