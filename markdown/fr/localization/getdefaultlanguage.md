# getdefaultlanguage

Renvoie la langue par défaut utilisée dans Nelson.

## 📝 Syntaxe

- lang = getdefaultlanguage()

## 📤 Argument de sortie

- lang - une chaîne : 'fr\_FR' par défaut.

## 📄 Description


<b>getdefaultlanguage</b> renvoie la langue par défaut utilisée par Nelson.

## 💡 Exemple



```matlab
getdefaultlanguage()
```
