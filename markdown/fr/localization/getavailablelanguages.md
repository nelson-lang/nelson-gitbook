# getavailablelanguages

Renvoie les langues disponibles dans Nelson.

## 📝 Syntaxe

- ce = getavailablelanguages()

## 📤 Argument de sortie

- ce - une cellule de chaînes : langues prises en charge.

## 📄 Description


<b>getavailablelanguages</b> renvoie la liste des langues actuellement prises en charge dans Nelson.

## 💡 Exemple



```matlab
getavailablelanguages()
```
