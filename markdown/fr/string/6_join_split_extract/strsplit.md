# strsplit

Decoupe un vecteur de caracteres aux delimiteurs.

## 📝 Syntaxe

- R = strsplit(...)

## 📄 Description


<b>strsplit</b> Decoupe un vecteur de caracteres aux delimiteurs.

## 💡 Exemple



```matlab
strsplit("a,b,c", ",")
```
