# strjoin

Joint le texte avec un delimiteur.

## 📝 Syntaxe

- R = strjoin(...)

## 📄 Description


<b>strjoin</b> Joint le texte avec un delimiteur.

## 💡 Exemple



```matlab
strjoin(["a", "b", "c"], ",")
```
