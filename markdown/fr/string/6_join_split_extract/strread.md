# strread

Lit des valeurs depuis un texte.

## 📝 Syntaxe

- R = strread(...)

## 📄 Description

<b>strread</b> Lit des valeurs depuis un texte.

## 💡 Exemple

```matlab
[A, B] = strread("1 one 2 two", "%d%s")
```
