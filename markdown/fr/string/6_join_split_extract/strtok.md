# strtok

Selectionne le premier jeton dans le texte.

## 📝 Syntaxe

- R = strtok(...)

## 📄 Description

<b>strtok</b> Selectionne le premier jeton dans le texte.

## 💡 Exemple

```matlab
[token, rest] = strtok("one two")
```
