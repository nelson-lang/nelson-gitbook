# splitlines

Decoupe le texte aux sauts de ligne.

## 📝 Syntaxe

- R = splitlines(...)

## 📄 Description

<b>splitlines</b> Decoupe le texte aux sauts de ligne.

## 💡 Exemple

```matlab
splitlines("a" + newline + "b")
```
