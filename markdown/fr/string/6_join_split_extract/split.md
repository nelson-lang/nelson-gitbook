# split

Decoupe le texte aux delimiteurs.

## 📝 Syntaxe

- R = split(...)

## 📄 Description

<b>split</b> Decoupe le texte aux delimiteurs.

## 💡 Exemple

```matlab
split("a,b,c", ",")
```
