# eraseBetween

Efface le texte entre des limites.

## 📝 Syntaxe

- R = eraseBetween(...)

## 📄 Description

<b>eraseBetween</b> Efface le texte entre des limites.

## 💡 Exemple

```matlab
eraseBetween("a[secret]b", "[", "]")
```
