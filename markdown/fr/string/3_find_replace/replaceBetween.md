# replaceBetween

Remplace le texte entre des limites.

## 📝 Syntaxe

- R = replaceBetween(...)

## 📄 Description

<b>replaceBetween</b> Remplace le texte entre des limites.

## 💡 Exemple

```matlab
replaceBetween("a[old]b", "[", "]", "new")
```
