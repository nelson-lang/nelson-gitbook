# findstr

Recherche un vecteur de caracteres dans un autre.

## 📝 Syntaxe

- R = findstr(...)

## 📄 Description

<b>findstr</b> Recherche un vecteur de caracteres dans un autre.

## 💡 Exemple

```matlab
findstr("hello", "l")
```
