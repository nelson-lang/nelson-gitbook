# strmatch

Recherche les chaines qui commencent par un texte.

## 📝 Syntaxe

- R = strmatch(...)

## 📄 Description

<b>strmatch</b> Recherche les chaines qui commencent par un texte.

## 💡 Exemple

```matlab
strmatch("max", ["max"; "min"; "maximum"])
```
