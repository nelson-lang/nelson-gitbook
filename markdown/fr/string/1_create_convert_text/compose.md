# compose

Formate les donnees en plusieurs chaines.

## 📝 Syntaxe

- R = compose(...)

## 📄 Description


<b>compose</b> Formate les donnees en plusieurs chaines.

## 💡 Exemple



```matlab
compose("value = %0.2f", pi)
```
