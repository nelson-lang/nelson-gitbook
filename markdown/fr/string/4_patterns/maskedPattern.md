# maskedPattern

Motif avec nom d'affichage.

## 📝 Syntaxe

- R = maskedPattern(...)

## 📄 Description

<b>maskedPattern</b> Motif avec nom d'affichage.

## 💡 Exemple

```matlab
pat = maskedPattern(digitsPattern(3), "area code"); extract("phone 123", pat)
```
