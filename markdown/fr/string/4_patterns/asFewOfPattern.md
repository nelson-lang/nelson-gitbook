# asFewOfPattern

Repete le motif le moins de fois possible.

## 📝 Syntaxe

- R = asFewOfPattern(...)

## 📄 Description

<b>asFewOfPattern</b> Repete le motif le moins de fois possible.

## 💡 Exemple

```matlab
pat = asFewOfPattern("b"); extract("abbbc", "a" + pat + "c")
```
