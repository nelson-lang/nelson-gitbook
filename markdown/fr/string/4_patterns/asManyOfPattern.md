# asManyOfPattern

Repete le motif autant de fois que possible.

## 📝 Syntaxe

- R = asManyOfPattern(...)

## 📄 Description

<b>asManyOfPattern</b> Repete le motif autant de fois que possible.

## 💡 Exemple

```matlab
pat = asManyOfPattern("b"); extract("abbbc", "a" + pat + "c")
```
