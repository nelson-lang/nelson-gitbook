# optionalPattern

Rend le motif optionnel.

## 📝 Syntaxe

- R = optionalPattern(...)

## 📄 Description


<b>optionalPattern</b> Rend le motif optionnel.

## 💡 Exemple



```matlab
pat = optionalPattern("u"); extract(["color"; "colour"], "colo" + pat + "r")
```
