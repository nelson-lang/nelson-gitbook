# digitBoundary

Limite pour le texte numerique.

## 📝 Syntaxe

- R = digitBoundary(...)

## 📄 Description

<b>digitBoundary</b> Limite pour le texte numerique.

## 💡 Exemple

```matlab
pat = digitBoundary("start") + digitsPattern(3); extract("ID123 A45", pat)
```
