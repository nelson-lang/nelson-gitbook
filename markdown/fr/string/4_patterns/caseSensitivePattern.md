# caseSensitivePattern

Recherche un motif en tenant compte de la casse.

## 📝 Syntaxe

- R = caseSensitivePattern(...)

## 📄 Description


<b>caseSensitivePattern</b> Recherche un motif en tenant compte de la casse.

## 💡 Exemple



```matlab
pat = caseSensitivePattern("nelson"); extract("Nelson nelson", pat)
```
