# isstrprop

Determine les categories de caracteres.

## 📝 Syntaxe

- R = isstrprop(...)

## 📄 Description

<b>isstrprop</b> Determine les categories de caracteres.

## 💡 Exemple

```matlab
isstrprop("A1 ", "alpha")
```
