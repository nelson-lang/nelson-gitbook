# while

boucle while.

## 📝 Syntaxe

- while test\_expression, statements, end

## 📄 Description


La boucle <b>while</b> exécute un ensemble d'instructions tant que la condition de test reste <b>true</b>.

## 💡 Exemple



```matlab

i = 0;
while lt(i, 10)
  disp(i)
  i = i + 1;
end

```
