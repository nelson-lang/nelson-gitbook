# abort

arrêter l'évaluation.

## 📝 Syntaxe

- abort
- return

## 📄 Description


<b>return</b> ou <b>abort</b> arrête l'évaluation en cours.

## 💡 Exemple



```matlab
for i=1:10,a = i,abort,end
          
```
