# Notebook


    
Le module Notebook exécute des documents Notebook en dehors de l'éditeur.

    
Un Notebook mêle texte mis en forme, code et ses sorties dans un même document. Ce module lit le conteneur natif **.nlx** et le format texte **.m**, et exécute leurs cellules de code dans l'espace de travail de base — un document peut donc être lancé depuis la ligne de commande ou un script.

  

## Functions

- [nlx](nlx.md) - Le format de document Notebook de Nelson (.nlx).
- [notebook](notebook.md) - Exécute un document Notebook.
