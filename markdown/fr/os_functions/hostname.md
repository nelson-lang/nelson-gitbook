# hostname

obtenir le nom d'hôte de cet ordinateur.

## 📝 Syntaxe

- s = hostname()

## 📤 Argument de sortie

- s - un tableau de caractères : nom d'hôte.

## 📄 Description


<b>hostname</b> renvoie le nom d'hôte de cet ordinateur.

## 💡 Exemple



```matlab
hostname()
```
