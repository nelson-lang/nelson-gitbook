# pwd

Renvoie le répertoire courant.

## 📝 Syntaxe

- pwd()
- r = pwd()

## 📤 Argument de sortie

- r - a string: répertoire courant.

## 📄 Description


Renvoie le répertoire de travail courant. 

<b>pwd()</b> sans argument affiche le répertoire courant. 



## 💡 Exemple



```matlab
r = pwd()
pwd()
```
