# genpath

Genere une chaine de chemin recursive.

## 📝 Syntaxe

- p = genpath(folder)

## 📄 Description

<b>genpath</b> retourne une chaine contenant <b>folder</b> et ses sous-dossiers inclus, separes par <b>pathsep</b>.

## 💡 Exemple

```matlab
p = genpath(tempdir())
```
