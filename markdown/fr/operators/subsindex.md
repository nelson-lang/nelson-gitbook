# subsindex

Convertir un objet en vecteur d'indices.

## 📝 Syntaxe

- r = subsindex(O)

## 📥 Argument d'entrée

- O - une variable

## 📄 Description


Si <b>O</b> est un objet alors <b>subsindex</b> est la méthode de surcharge qui permet de convertir cet objet en un vecteur d'indexation valide.
