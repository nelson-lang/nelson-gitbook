# minus

Soustraction, opérateur -

## 📝 Syntaxe

- C = minus(A, B)
- C = A - B

## 📥 Argument d'entrée

- A - une variable
- B - une variable

## 📤 Argument de sortie

- C - résultat de A - B

## 📄 Description


<b>C = minus(A, B)</b> effectue la soustraction A - B des variables.

## 💡 Exemples



```matlab
minus(3, 4)
3 - 4
```


```matlab
[1, 2] - 1
minus([1, 2], 1)
```


```matlab
ones(0, 0) - 1
```
Soustraire des valeurs numeriques a des codes caractere.

```matlab
char(65) - 1
int8([1 2]) - char(65)
```
