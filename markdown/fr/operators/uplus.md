# uplus

Unaire plus, opérateur +

## 📝 Syntaxe

- C = uplus(A)
- C = +A

## 📥 Argument d'entrée

- A - une variable

## 📤 Argument de sortie

- C - résultat de +A

## 📄 Description


<b>C = uplus(A)</b> effectue l'opération unaire plus, c.-à-d. +A.

## 💡 Exemple



```matlab
M = -3;
+M
```
