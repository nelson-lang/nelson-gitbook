# plus

Addition, opérateur +

## 📝 Syntaxe

- C = plus(A, B)
- C = A + B

## 📥 Argument d'entrée

- A - une variable
- B - une variable

## 📤 Argument de sortie

- C - résultat de A + B

## 📄 Description

<b>C = plus(A, B)</b> effectue l'addition A + B.

## 💡 Exemples

```matlab
plus(3, 4)
3 + 4
```

```matlab
[1, 2] + 1
plus([1, 2], 1)
```

```matlab
ones(0, 0) + 1
```

Ajouter un code caractere et une valeur numerique.

```matlab
char(65) + 1
char(65) + int8([1 2])
```
