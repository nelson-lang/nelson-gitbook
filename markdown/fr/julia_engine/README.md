# Moteur Julia

Le module Julia Engine permet à Nelson d'appeler du code Julia et d'utiliser des bibliothèques numériques Julia depuis l'environnement Nelson.

Il fournit des fonctions pour exécuter du code Julia, gérer les environnements d'interpréteur et échanger des données entre Nelson et Julia.

## Functions

- [jlenv](jlenv.md) - Modifier l'environnement par défaut de l'interpréteur Julia.
- [jlrun](jlrun.md) - Exécute des instructions Julia depuis Nelson.
- [jlrunfile](jlrunfile.md) - Exécute un fichier Julia depuis Nelson.
- [Julia Nelson types](julia_types.md) - Gestion des données entre Julia et Nelson.
