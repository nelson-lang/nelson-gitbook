# stdin

Identifiant du flux d'entrée standard.

## 📝 Syntaxe

- fd = stdin()

## 📤 Argument de sortie

- fd - la valeur <b>0</b>.

## 📄 Description


<b>fd = stdin()</b> renvoie <b>0</b>, l'identifiant du flux d'entrée standard.

## 💡 Exemple



```matlab
fd = stdin()
```
