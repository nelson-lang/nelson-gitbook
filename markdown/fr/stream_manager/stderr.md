# stderr

Identifiant du flux d'erreur standard.

## 📝 Syntaxe

- fd = stderr()

## 📤 Argument de sortie

- fd - la valeur <b>2</b>.

## 📄 Description


<b>fd = stderr()</b> renvoie <b>2</b>, l'identifiant du flux d'erreur standard.

## 💡 Exemple



```matlab
fprintf(stderr(), 'Hello\n');
```
