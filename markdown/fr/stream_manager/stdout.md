# stdout

Identifiant du flux de sortie standard.

## 📝 Syntaxe

- fd = stdout()

## 📤 Argument de sortie

- fd - la valeur <b>1</b>.

## 📄 Description


<b>fd = stdout()</b> renvoie <b>1</b>, l'identifiant du flux de sortie standard.

## 💡 Exemple



```matlab
fprintf(stdout(), 'Hello\n');
```
