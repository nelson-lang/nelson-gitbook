# SEEK\_SET

Valeur d'origine pour fseek : au début du fichier.

## 📝 Syntaxe

- id = SEEK\_SET()

## 📤 Argument de sortie

- id - la valeur <b>-1</b>.

## 📄 Description


<b>id = SEEK\_SET()</b> renvoie la valeur numérique d'origine à passer à <b>fseek</b> pour positionner le fichier par rapport au début du fichier.

## 💡 Exemple



```matlab
id = SEEK_SET()
```
