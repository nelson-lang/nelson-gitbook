# SEEK\_CUR

Valeur d'origine pour fseek : à la position courante.

## 📝 Syntaxe

- id = SEEK\_CUR()

## 📤 Argument de sortie

- id - la valeur <b>0</b>.

## 📄 Description


<b>id = SEEK\_CUR()</b> renvoie la valeur numérique d'origine à passer à <b>fseek</b> pour positionner le fichier par rapport à la position courante.

## 💡 Exemple



```matlab
id = SEEK_CUR()
```
