# SEEK\_END

Valeur d'origine pour fseek : à la fin du fichier.

## 📝 Syntaxe

- id = SEEK\_END()

## 📤 Argument de sortie

- id - la valeur <b>1</b>.

## 📄 Description


<b>id = SEEK\_END()</b> renvoie la valeur numérique d'origine à passer à <b>fseek</b> pour positionner le fichier par rapport à la fin du fichier.

## 💡 Exemple



```matlab
id = SEEK_END()
```
