# timeseries.std

Écart-type des données d'un timeseries.

## 📝 Syntaxe

- y = std(ts)

## 📥 Argument d'entrée

- ts - Objet timeseries en entrée.

## 📤 Argument de sortie

- y - Écart-type des données du timeseries.

## 📄 Description


<b>std</b> calcule l'écart-type de la propriété Data.

## 💡 Exemple


```matlab
ts = timeseries([1; 2; 3]);
std(ts)

```
