# timeseries.display

Affiche un objet timeseries.

## 📝 Syntaxe

- display(ts)

## 📥 Argument d'entrée

- ts - Un objet timeseries.

## 📄 Description


<b>display</b> affiche un objet timeseries avec son nom de variable lorsqu'il est disponible.

## 💡 Exemple


```matlab
ts = timeseries([1; 2; 3], [10; 11; 12], 'Name', 'speed');
display(ts)

```
