# tsdata.event

Fonction pour objets de serie temporelle.

## 📝 Syntaxe

- event(...)

## 📄 Description


<b>event</b> opere sur les objets timeseries, tscollection ou les metadonnees tsdata.

## 💡 Exemple


```matlab
morning = tsdata.event('AMCommute', 2);
morning.Units = 'hours';
morning.Time

```
