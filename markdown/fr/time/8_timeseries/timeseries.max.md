# timeseries.max

Maximum des données d'un timeseries.

## 📝 Syntaxe

- y = max(ts)

## 📥 Argument d'entrée

- ts - Objet timeseries en entrée.

## 📤 Argument de sortie

- y - Maximum des données du timeseries.

## 📄 Description


<b>max</b> calcule le maximum sur la propriété Data.

## 💡 Exemple


```matlab
ts = timeseries([1; 3; 2]);
max(ts)

```
