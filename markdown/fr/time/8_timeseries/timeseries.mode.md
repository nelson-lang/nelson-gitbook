# timeseries.mode

Mode des données d'un timeseries.

## 📝 Syntaxe

- y = mode(ts)

## 📥 Argument d'entrée

- ts - Objet timeseries en entrée.

## 📤 Argument de sortie

- y - Mode des données du timeseries.

## 📄 Description


<b>mode</b> calcule le mode de la propriété Data.

## 💡 Exemple


```matlab
ts = timeseries([1; 2; 2; 3]);
mode(ts)

```
