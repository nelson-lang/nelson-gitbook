# timeseries.var

Variance des données d'un timeseries.

## 📝 Syntaxe

- y = var(ts)

## 📥 Argument d'entrée

- ts - Objet timeseries en entrée.

## 📤 Argument de sortie

- y - Variance des données du timeseries.

## 📄 Description


<b>var</b> calcule la variance de la propriété Data.

## 💡 Exemple


```matlab
ts = timeseries([1; 2; 3]);
var(ts)

```
