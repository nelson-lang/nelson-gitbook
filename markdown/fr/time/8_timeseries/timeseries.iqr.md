# timeseries.iqr

Écart interquartile des données d'un timeseries.

## 📝 Syntaxe

- y = iqr(ts)

## 📥 Argument d'entrée

- ts - Objet timeseries en entrée.

## 📤 Argument de sortie

- y - Écart interquartile des données du timeseries.

## 📄 Description


<b>iqr</b> calcule l'écart interquartile de la propriété Data.

## 💡 Exemple


```matlab
ts = timeseries([1; 2; 3; 4]);
iqr(ts)

```
