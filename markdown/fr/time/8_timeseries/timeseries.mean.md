# timeseries.mean

Moyenne des données d'un timeseries.

## 📝 Syntaxe

- y = mean(ts)

## 📥 Argument d'entrée

- ts - Objet timeseries en entrée.

## 📤 Argument de sortie

- y - Moyenne des données du timeseries.

## 📄 Description

<b>mean</b> calcule la moyenne arithmétique de la propriété Data.

## 💡 Exemple

```matlab
ts = timeseries([1; 2; 3]);
mean(ts)

```
