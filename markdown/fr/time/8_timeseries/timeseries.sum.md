# timeseries.sum

Somme des données d'un timeseries.

## 📝 Syntaxe

- y = sum(ts)

## 📥 Argument d'entrée

- ts - Objet timeseries en entrée.

## 📤 Argument de sortie

- y - Somme des données du timeseries.

## 📄 Description

<b>sum</b> calcule la somme de la propriété Data.

## 💡 Exemple

```matlab
ts = timeseries([1; 2; 3]);
sum(ts)

```
