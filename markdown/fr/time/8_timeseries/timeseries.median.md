# timeseries.median

Médiane des données d'un timeseries.

## 📝 Syntaxe

- y = median(ts)

## 📥 Argument d'entrée

- ts - Objet timeseries en entrée.

## 📤 Argument de sortie

- y - Médiane des données du timeseries.

## 📄 Description


<b>median</b> calcule la médiane de la propriété Data.

## 💡 Exemple


```matlab
ts = timeseries([1; 5; 3]);
median(ts)

```
