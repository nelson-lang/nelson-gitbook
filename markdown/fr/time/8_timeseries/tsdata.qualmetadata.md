# tsdata.qualmetadata

Fonction pour objets de serie temporelle.

## 📝 Syntaxe

- qualmetadata(...)

## 📄 Description

<b>qualmetadata</b> opere sur les objets timeseries, tscollection ou les metadonnees tsdata.

## 💡 Exemple

```matlab
info = tsdata.qualmetadata('Code', [1], 'Description', {'ok'});
info.Description

```
