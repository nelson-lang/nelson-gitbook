# istimeseries

Determine si l entree est un objet timeseries.

## 📝 Syntaxe

- tf = istimeseries(value)

## 📥 Argument d'entrée

- value - Valeur d entree.

## 📤 Argument de sortie

- tf - Resultat logique.

## 📄 Description


<b>istimeseries</b> retourne true lorsque l entree est un objet timeseries.

## 💡 Exemple


```matlab
ts = timeseries([1; 2], [10; 11]);
istimeseries(ts)

```
