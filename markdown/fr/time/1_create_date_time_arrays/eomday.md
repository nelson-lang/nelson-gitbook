# eomday

Retourne le dernier jour du mois.

## 📝 Syntaxe

- E = eomday(Y, M)

## 📥 Argument d'entrée

- Y - année : réel.
- M - mois : réel.

## 📤 Argument de sortie

- E - dernier jour du mois : réel.

## 📄 Description


<b>E = eomday(Y, M)</b> retourne le dernier jour du mois<b>M</b> pour l'année <b>Y</b>.

## 💡 Exemple



```matlab
eomday(1900, 1:12)
```
