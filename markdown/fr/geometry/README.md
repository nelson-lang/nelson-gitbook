# Geometrie


    
Le module Geometrie fournit des outils pour effectuer des transformations et calculs geometriques dans Nelson.

    
Il prend en charge les rotations en espace tridimensionnel, les enveloppes convexes, les triangulations de Delaunay, les diagrammes de Voronoi, les recherches spatiales et l'interpolation de donnees dispersees.

    
Ce module est utile pour l'infographie, la robotique, la geometrie algorithmique, l'interpolation et l'analyse spatiale.

  

## Functions

- [alphaShape](alphaShape.md) - Objet alpha shape
- [axes2ecc](axes2ecc.md) - Excentricité d'une ellipse à partir de ses demi-axes.
- [boundary](boundary.md) - Facettes frontiere d'un ensemble de points
- [convhull](convhull.md) - Enveloppe convexe de points 2-D ou 3-D
- [convhulln](convhulln.md) - Enveloppe convexe en N dimensions
- [delaunay](delaunay.md) - Triangulation de Delaunay de points 2-D ou 3-D
- [delaunayTriangulation](delaunayTriangulation.md) - Objet de triangulation de Delaunay
- [delaunayn](delaunayn.md) - Triangulation de Delaunay en N dimensions
- [dsearchn](dsearchn.md) - Recherche du point le plus proche
- [ellipse1](ellipse1.md) - Points d'une petite ellipse sur une sphère.
- [griddata](griddata.md) - Interpolation de donnees dispersees
- [nsidedpoly](nsidedpoly.md) - Crée un polygone régulier.
- [polyarea](polyarea.md) - Aire d'un polygone.
- [polyshape](polyshape.md) - Crée un polygone.
- [reckon](reckon.md) - Point à une distance sphérique et un azimut donnés.
- [rectint](rectint.md) - Aire d'intersection de rectangles.
- [rotx](rotx.md) - Matrice de transformation 3x3 pour rotation autour de l'axe x
- [roty](roty.md) - Matrice de transformation 3x3 pour rotation autour de l'axe y
- [rotz](rotz.md) - Matrice de transformation 3x3 pour rotation autour de l'axe z
- [scatteredInterpolant](scatteredInterpolant.md) - Objet d'interpolation de donnees dispersees
- [stlread](stlread.md) - Creer une triangulation depuis un fichier STL
- [stlwrite](stlwrite.md) - Creer un fichier STL depuis une triangulation
- [triangulation](triangulation.md) - Objet de triangulation
- [tsearchn](tsearchn.md) - Localisation de point dans une triangulation
- [voronoi](voronoi.md) - Diagramme de Voronoi de points plans
- [voronoin](voronoin.md) - Diagramme de Voronoi en N dimensions
