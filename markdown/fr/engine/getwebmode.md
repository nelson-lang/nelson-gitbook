# getwebmode

Renvoie le mode de lancement effectif de Nelson WebView.

## 📝 Syntaxe

- mode = getwebmode()

## 📤 Argument de sortie

- mode - <b>'webview'</b>, <b>'server'</b> ou <b>'none'</b>.

## 📄 Description

<b>getwebmode()</b> indique comment le bureau Nelson WebView courant a effectivement ete lance. La fonction renvoie <b>'none'</b> en dehors d'un lancement web actif.

## 💡 Exemple

```matlab
getwebmode()
```
