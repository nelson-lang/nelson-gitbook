# Exigences système

Exigences système par plateforme.

## 📄 Description


<b>Linux</b> : 

<b>Système d'exploitation</b> : Ubuntu 24.04 LTS, Ubuntu 22.04 LTS, Ubuntu 20.04 LTS, Fedora, ArchLinux, NixOs 

<b>Processeur</b> : tout processeur Intel ou AMD x86-64. 

<b>Mémoire (RAM)</b> : voir les exigences du système d'exploitation (16 Go recommandés ou plus). 

<b>Stockage</b> : 1 Go pour l'installation de tous les produits ; un SSD/NVMe est recommandé. 

<b>Graphisme</b> : un GPU avec accélération matérielle et support OpenGL et au moins 1 Go de mémoire est recommandé. 

 

<b>Windows</b> : 

<b>Système d'exploitation</b> : Windows 10, 11 ou Windows Server 2022. 

<b>Processeur</b> : tout processeur Intel ou AMD x86-64 avec jeu d'instructions AVX2 (CPU publié à partir de 2015). 

<b>Mémoire (RAM)</b> : voir les exigences du système d'exploitation (16 Go recommandés ou plus). 

<b>Stockage</b> : 1 Go pour l'installation de tous les produits ; un SSD/NVMe est recommandé. 

<b>Graphisme</b> : un GPU avec accélération matérielle et support OpenGL et au moins 1 Go de mémoire est recommandé. 

 

<b>MacOs</b> : 

<b>Système d'exploitation</b> : macOS Tahoe, macOS Sequoia, macOS Sonoma, macOS Ventura. 

<b>Processeur</b> : tout processeur Intel supporté par Apple et tout processeur de la série M. 

<b>Stockage</b> : 1 Go pour l'installation de tous les produits ; un SSD/NVMe est recommandé. 

<b>Graphisme</b> : tout Mac capable d'exécuter macOS Ventura dispose d'un GPU pouvant exécuter Nelson.
