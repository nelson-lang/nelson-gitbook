# Traitement XML

Le module XML fournit des fonctions pour créer, convertir et gérer des documents XML pour Nelson.

## Functions

- [readstruct](readstruct.md) - Lire des données XML comme structure
- [writestruct](writestruct.md) - Écrire une structure comme XML
- [xmlchecker](xmlchecker.md) - Vérifie un fichier XML par rapport à un XSD.
- [xmlprettyprint](xmlprettyprint.md) - formate un fichier XML.
- [xmlread](xmlread.md) - Lire un fichier XML comme objet document
- [xmltransform](xmltransform.md) - Transformation XML utilisant XSLT
- [xmlwrite](xmlwrite.md) - Sérialiser un objet document XML
- [xslt](xslt.md) - Transformer du XML avec XSLT
