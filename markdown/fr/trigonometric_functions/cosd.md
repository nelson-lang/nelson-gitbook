# cosd

Calcule le cosinus en degrés pour chaque élément de x.

## 📝 Syntaxe

- res = cosd(x)

## 📥 Argument d'entrée

- x - une valeur numérique

## 📤 Argument de sortie

- res - une valeur numérique

## 📄 Description


<b>cosd</b> calcule le cosinus en degrés pour chaque élément de <b>x</b>.

## 💡 Exemple



```matlab
A = [0 30 45 60 90 360];;
res = cosd(A)
```
