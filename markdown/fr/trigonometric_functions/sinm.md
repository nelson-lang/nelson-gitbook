# sinm

Calcule le sinus matriciel d'une matrice carrée.

## 📝 Syntaxe

- res = sinm(x)

## 📥 Argument d'entrée

- x - une valeur numérique : scalaire ou matrice carrée

## 📤 Argument de sortie

- res - une valeur numérique : une matrice carrée

## 📄 Description


<b>sinm(x)</b> calcule le sinus matriciel de <b>x</b>.

## 💡 Exemple



```matlab
A = eye(3, 3);
res = sinm(A)
A = [1, 2; 3, 4];
res = sinm(A)
```
