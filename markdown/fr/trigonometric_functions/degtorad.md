# degtorad

Convertit un angle de degrés en radians.

## 📝 Syntaxe

- r = degtorad(d)

## 📥 Argument d'entrée

- d - une valeur numérique (double ou simple)

## 📤 Argument de sortie

- r - une valeur numérique

## 📄 Description
<b>r = degtorad(d)</b> convertit les unités d'angle de degrés en radians pour chaque élément de <b>d</b>.

## 💡 Exemple



```matlab
D = 64.7;
R = degtorad(D);
radEarth = 6371;
dist = radEarth * R
```
