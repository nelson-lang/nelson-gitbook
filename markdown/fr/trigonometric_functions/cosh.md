# cosh

Calcule le cosinus hyperbolique en radians pour chaque élément de x.

## 📝 Syntaxe

- res = cosh(x)

## 📥 Argument d'entrée

- x - une valeur numérique

## 📤 Argument de sortie

- res - une valeur numérique

## 📄 Description
<b>cosh</b> calcule le cosinus hyperbolique en radians pour chaque élément de <b>x</b>.

## 💡 Exemple



```matlab
A = eye(3, 3);
res = cosh(A)
```
