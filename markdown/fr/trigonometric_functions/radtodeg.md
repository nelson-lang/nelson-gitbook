# radtodeg

Convertit un angle de radians en degrés.

## 📝 Syntaxe

- d = radtodeg(r)

## 📥 Argument d'entrée

- r - une valeur numérique (double ou simple)

## 📤 Argument de sortie

- d - une valeur numérique

## 📄 Description
<b>d = radtodeg(r)</b> convertit les unités d'angle de radians en degrés pour chaque élément de <b>r</b>.

## 💡 Exemple



```matlab
dist = 7194;
radEarth = 6371;
D = radtodeg(dist / radEarth)
```
