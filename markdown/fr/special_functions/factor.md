# factor

Facteurs premiers

## 📝 Syntaxe

- f = factor(n)

## 📥 Argument d'entrée

- n - scalaire entier réel, non négatif

## 📤 Argument de sortie

- p - vecteur avec les facteurs premiers.

## 📄 Description


<b>f = factor(n)</b> retourne un vecteur ligne avec les facteurs premiers de <b>n</b>. 

Le vecteur <b>f</b> est du même type de données que <b>n</b>.

## 💡 Exemple



```matlab
f = factor(204)
```
