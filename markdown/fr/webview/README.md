# Web view


    
Le module WebView ouvre du HTML local, du texte HTML, des adresses web et la galerie d’exemples depuis Nelson.

  

## Functions

- [demo](demo.md) - Parcourir les exemples des modules Nelson et des toolboxes externes charges.
- [nelson.htmlviewer.htmlviewer](nelson_htmlviewer_htmlviewer.md) - Handle vers une fenetre du visualiseur HTML Nelson.
- [web](web.md) - Ouvre une page web, un fichier local ou du texte HTML.
