# clc

Effacer la fenêtre de commande.

## 📝 Syntaxe

- clc()

## 📄 Description


<b>clc()</b> efface la console et déplace le curseur vers le coin supérieur gauche.

## 💡 Exemple



```matlab
disp('Hello');
clc()

```
