# median

Valeur mediane des elements d'un tableau.

## 📝 Syntaxe

- R = median(M)
- R = median(M, d)
- R = median(M, 'all')
- R = median(..., 'omitnan')

## 📄 Description

<b>median</b> renvoie la valeur centrale des donnees triees selon la dimension choisie.

## 💡 Exemple

```matlab
R = median([4 1 2 3])
```
