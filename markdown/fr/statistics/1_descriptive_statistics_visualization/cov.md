# cov

Covariance

## 📝 Syntaxe

- C = cov(M)

## 📥 Argument d'entrée

- M - un vecteur ou une matrice

## 📤 Argument de sortie

- V - Covariance de M.

## 📄 Description


<b>C = cov(M)</b> renvoie la covariance.

## Fonction(s) utilisée(s)


    corrcoef
    std
    var
  

## 💡 Exemple



```matlab
M = [4 -7 3; 1 4 -2; 10 7 9];
C = cov(M)
```
