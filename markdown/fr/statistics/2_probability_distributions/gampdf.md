# gampdf

Densite de probabilite gamma

## 📝 Syntaxe

- y = gampdf(x, a)
- y = gampdf(x, a, b)

## 📥 Argument d'entrée

- x - tableau numerique reel.
- a - parametre de forme positif.
- b - parametre d'echelle positif, 1 par defaut.

## 📤 Argument de sortie

- y - valeurs de densite de probabilite.

## 📄 Description


<b>gampdf</b> calcule les valeurs de densite de la distribution gamma.

## 💡 Exemple



```matlab
x = [0 0.5 1 2 5];
y = gampdf(x, 2, 3);
```
