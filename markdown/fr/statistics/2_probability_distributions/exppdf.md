# exppdf

Densite de probabilite exponentielle

## 📝 Syntaxe

- y = exppdf(x)
- y = exppdf(x, mu)

## 📥 Argument d'entrée

- x - tableau numerique reel.
- mu - moyenne positive, 1 par defaut.

## 📤 Argument de sortie

- y - valeurs de densite de probabilite.

## 📄 Description

<b>exppdf</b> calcule les valeurs de densite de la distribution exponentielle.

## 💡 Exemple

```matlab
x = [0 0.5 1 2];
y = exppdf(x, 3);
```
