# raylstat

Moyenne et variance Rayleigh

## 📝 Syntaxe

- [m, v] = raylstat(b)

## 📥 Argument d'entrée

- b - scalaire positif ou tableau : parametre d'echelle.

## 📤 Argument de sortie

- m - tableau : moyennes.
- v - tableau : variances.

## 📄 Description


<b>raylstat</b> renvoie la moyenne et la variance element par element de lois Rayleigh.

## 💡 Exemple



```matlab
[m, v] = raylstat(2);
```
