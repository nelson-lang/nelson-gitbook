# unidpdf

Probabilites de loi uniforme discrete

## 📝 Syntaxe

- y = unidpdf(x, n)

## 📥 Argument d'entrée

- x - tableau numerique reel.
- n - scalaire entier positif ou tableau : valeur maximale.

## 📤 Argument de sortie

- y - probabilites.

## 📄 Description

<b>unidpdf</b> calcule les probabilites de la loi uniforme discrete sur les entiers de 1 a <b>n</b>.

## 💡 Exemple

```matlab
x = 0:6;
y = unidpdf(x, 5);
```
