# unifpdf

Densite de probabilite uniforme continue

## 📝 Syntaxe

- y = unifpdf(x)
- y = unifpdf(x, a, b)

## 📥 Argument d'entrée

- x - tableau numerique reel.
- a - borne inferieure, 0 par defaut.
- b - borne superieure, 1 par defaut.

## 📤 Argument de sortie

- y - valeurs de densite de probabilite.

## 📄 Description


<b>unifpdf</b> calcule les valeurs de densite de la distribution uniforme continue.

## 💡 Exemple



```matlab
x = 0:0.25:1;
y = unifpdf(x);
```
