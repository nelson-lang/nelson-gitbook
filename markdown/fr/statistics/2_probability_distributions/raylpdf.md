# raylpdf

Densite de probabilite Rayleigh

## 📝 Syntaxe

- y = raylpdf(x, b)

## 📥 Argument d'entrée

- x - scalaire reel ou tableau : valeurs.
- b - scalaire positif ou tableau : parametre d'echelle.

## 📤 Argument de sortie

- y - tableau : valeurs de densite.

## 📄 Description


<b>raylpdf</b> evalue les densites Rayleigh element par element.

## 💡 Exemple



```matlab
x = [0 2 4];
y = raylpdf(x, 2);
```
