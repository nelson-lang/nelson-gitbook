# poisspdf

Fonction de masse de Poisson

## 📝 Syntaxe

- y = poisspdf(x, lambda)

## 📥 Argument d'entrée

- x - tableau numerique reel.
- lambda - parametre de taux non negatif.

## 📤 Argument de sortie

- y - valeurs de masse de probabilite.

## 📄 Description


<b>poisspdf</b> calcule les valeurs de masse de probabilite de Poisson.

## 💡 Exemple



```matlab
x = 0:10;
y = poisspdf(x, 4);
```
