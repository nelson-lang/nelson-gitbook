# betapdf

Densite de probabilite beta

## 📝 Syntaxe

- y = betapdf(x, a, b)

## 📥 Argument d'entrée

- x - tableau numerique reel.
- a - premier parametre de forme positif.
- b - second parametre de forme positif.

## 📤 Argument de sortie

- y - valeurs de densite de probabilite.

## 📄 Description

<b>betapdf</b> calcule les valeurs de densite de la distribution beta.

## 💡 Exemple

```matlab
x = [0 0.1 0.5 0.9 1];
y = betapdf(x, 2, 5);
```
