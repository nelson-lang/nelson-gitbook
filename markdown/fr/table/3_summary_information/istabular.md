# istabular

Determiner si l'entree est un objet tabulaire.

## 📝 Syntaxe

- tf = istabular(A)

## 📥 Argument d'entrée

- A - Tableau d'entree.

## 📤 Argument de sortie

- tf - Scalaire logique.

## 📄 Description

<b>istabular(A)</b> renvoie vrai quand <b>A</b> est une table ou une timetable.

## 💡 Exemple

```matlab
T = table([1; 2]);
istabular(T)
```
