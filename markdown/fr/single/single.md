# single

Convertit une variable en type simple précision.

## 📝 Syntaxe

- S = single(V)

## 📥 Argument d'entrée

- V - une variable.

## 📤 Argument de sortie

- S - une variable simple précision.

## 📄 Description


<b>single(V)</b> convertit vers le type simple précision.

## 💡 Exemples



```matlab
single('Nelson')
```


```matlab
A = single(pi)
```
