# audioplayer\_used

Retourne la liste des handles audioplayer actuellement utilisés.

## 📝 Syntaxe

- r = audioplayer\_used()

## 📤 Argument de sortie

- h - un vecteur de handles audioplayer.

## 📄 Description


Retourne la liste des handles audioplayer actuellement utilisés.

## 💡 Exemple



```matlab
used = audioplayer_used()
```
