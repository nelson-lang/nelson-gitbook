# audioplayer_delete

Supprime l'objet audioplayer.

## 📝 Syntaxe

- audioplayer_delete(h)
- delete(h)

## 📥 Argument d'entrée

- h - un handle : un objet audioplayer.

## 📄 Description

<b>delete(h)</b> libère l'objet audioplayer.

N'oubliez pas de vider h ensuite.

## 💡 Exemple

```matlab
used = audioplayer_used()
```
