# dlsym\_delete

Supprime l'objet dlsym

## 📝 Syntaxe

- dlsym\_delete(h)
- delete(h)

## 📥 Argument d'entrée

- h - un handle : un objet dlsym.

## 📄 Description


<b>delete(h)</b> libère l'objet dlsym. 

N'oubliez pas de nettoyer la variable h ensuite.

## 💡 Exemple



```matlab
used = dlsym_used()
```
