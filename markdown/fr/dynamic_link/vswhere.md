# vswhere

Localiser les installations de Visual Studio (2017, 2019 et versions ultérieures)

## 📝 Syntaxe

- res = vswhere()

## 📤 Argument de sortie

- res - a struct with information about Visual studio

## 📄 Description


<b>vswhere</b> permet de trouver facilement Visual Studio. 

<b>vswhere</b> est actuellement implémenté seulement sur la plateforme Windows.

## 📚 Bibliographie

https://github.com/Microsoft/vswhere

## 💡 Exemple



```matlab
vswhere()
```
