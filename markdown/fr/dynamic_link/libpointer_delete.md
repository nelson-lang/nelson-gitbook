# libpointer_delete

Supprime l'objet libpointer

## 📝 Syntaxe

- libpointer_delete(h)
- delete(h)

## 📥 Argument d'entrée

- h - un handle : un objet libpointer.

## 📄 Description

<b>delete(h)</b> libère l'objet libpointer.

N'oubliez pas de nettoyer la variable h ensuite.

## 💡 Exemple

```matlab
used = libpointer_used()
```
