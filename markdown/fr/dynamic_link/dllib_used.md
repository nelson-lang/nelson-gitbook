# dllib_used

Renvoie la liste des handles dllib actuellement utilisés

## 📝 Syntaxe

- r = dllib_used()

## 📤 Argument de sortie

- h - un vecteur de handles dllib.

## 📄 Description

Renvoie la liste des handles dllib actuellement utilisés.

## 💡 Exemple

```matlab
used = dllib_used()
```
