# qml\_loadfile

Charger un fichier QML.

## 📝 Syntaxe

- h = qml\_loadfile(filename)

## 📥 Argument d'entrée

- filename - une chaîne : nom de fichier QML.

## 📤 Argument de sortie

- h - une poignée (handle) QObject.

## 📄 Description


Charge un fichier QML 

Il crée un composant QML et charge le fichier .qml.
