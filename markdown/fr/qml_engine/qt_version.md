# qt_version

Renvoie la version de Qt utilisée.

## 📝 Syntaxe

- v = qt_version()

## 📤 Argument de sortie

- v - une chaîne : numéro de version.

## 📄 Description

<b>v = qt_version()</b> renvoie le numéro de version de Qt à l'exécution sous forme de chaîne (par exemple, "6.2.4").

## 💡 Exemple

```matlab
semver(qt_version(), '>=6.2')
```
