# MPI\_Comm\_object

Crée un objet MPI\_Comm.

## 📝 Syntaxe

- comm = MPI\_Comm\_object()
- comm = MPI\_Comm\_object(str)

## 📥 Argument d'entrée

- str - une chaîne : MPI\_COMM\_SELF ou MPI\_COMM\_WORLD.

## 📄 Description


<b>MPI\_Comm\_object(h)</b> crée un objet MPI\_Comm.

## 💡 Exemple

CLI required

```matlab
used = MPI_Comm_used()
```
