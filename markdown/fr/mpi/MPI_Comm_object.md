# MPI_Comm_object

Crée un objet MPI_Comm.

## 📝 Syntaxe

- comm = MPI_Comm_object()
- comm = MPI_Comm_object(str)

## 📥 Argument d'entrée

- str - une chaîne : MPI_COMM_SELF ou MPI_COMM_WORLD.

## 📄 Description

<b>MPI_Comm_object(h)</b> crée un objet MPI_Comm.

## 💡 Exemple

CLI required

```matlab
used = MPI_Comm_used()
```
