# doc

Affiche la documentation.

## 📝 Syntaxe

- doc
- doc function\_name
- doc('function\_name')

## 📥 Argument d'entrée

- function\_name - une chaîne : nom de la fonction

## 📄 Description


<b>doc</b> lance le navigateur d'aide. 

<b>doc('function\_name')</b> affiche l'aide de la fonction indiquée par 'function\_name'.

## 💡 Exemples



```matlab
doc()
```


```matlab
doc sin
```


```matlab
doc is
```
