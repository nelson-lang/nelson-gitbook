# buildhelpjson

Construire l'aide de Nelson au format JSON.

## 📝 Syntaxe

- buildhelpjson()

## 📄 Description


<b>buildhelpjson</b> génère des fichiers d'aide (au format JSON) (fonctionnalité interne).

## 💡 Exemple



```matlab
buildhelpjson();
```
