# nelsonappid

Identifiant de l'application Nelson.

## 📝 Syntaxe

- nelsonappid()

## 📄 Description


Renvoie l'identifiant unique utilisé par l'application Nelson sur cette installation.

## 💡 Exemple



```matlab
nelsonappid()
```
