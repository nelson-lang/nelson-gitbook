# exit

Quitte l'environnement Nelson.

## 📝 Syntaxe

- exit
- exit(status)
- exit('force')
- exit('cancel')
- exit(status, 'force')

## 📄 Description


Ferme l'environnement Nelson ou termine la session en cours.
