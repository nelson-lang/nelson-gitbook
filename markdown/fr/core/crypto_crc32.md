# crypto.crc32

Somme de contrôle CRC-32 (alias de l'espace crypto).

## 📝 Syntaxe

- hexa_hash = crypto.crc32(...)

## 📥 Argument d'entrée

- ... - voir <b>crc32</b>.

## 📤 Argument de sortie

- hexa_hash - chaîne hexadécimale, identique à <b>crc32</b>.

## 📄 Description

<b>crypto.crc32</b> est un alias de <b>crc32</b>, dans l'espace de noms <b>crypto</b> (mêmes arguments et même résultat).
