# nelsonroot

Répertoire racine de Nelson.

## 📝 Syntaxe

- nelson\_path = nelsonroot

## 📤 Argument de sortie

- nelson\_path - a string: the root folder of Nelson.

## 📄 Description


Renvoie le répertoire racine où Nelson est installé ou configuré.

## 💡 Exemple



```matlab
pwd
cd(nelsonroot)
pwd
```
