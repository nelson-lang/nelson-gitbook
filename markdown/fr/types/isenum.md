# isenum

Détermine si l'entrée est une énumération

## 📝 Syntaxe

- tf = isenum(X)

## 📥 Argument d'entrée

- X - valeur d'entrée.

## 📤 Argument de sortie

- tf - scalaire logique, vrai si X est une énumération.

## 📄 Description


<b>isenum</b> retourne vrai si X est une instance d'une classe d'énumération, et faux sinon.

## 💡 Exemple



```matlab
tf = isenum(3)
```
