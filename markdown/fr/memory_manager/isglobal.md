# isglobal

Vérifie si une variable est globale.

## 📝 Syntaxe

- state = isglobal(variable\_name)

## 📥 Argument d'entrée

- variable\_name - une chaîne : nom de la variable.

## 📤 Argument de sortie

- state - un booléen : vrai si la variable est globale.

## 📄 Description


<b>isglobal</b> renvoie vrai si<b>variable\_name</b> a été déclarée comme variable globale, et faux sinon.

## 💡 Exemple



```matlab
y = 3;
isglobal y
global b
b = 3
isglobal b
clear global b
isglobal b
```
