# nelson.unittest.skip

Ignorer le test courant.

## 📝 Syntaxe

- nelson.unittest.skip()
- nelson.unittest.skip(reason)
- nelson.unittest.skip(condition, reason)

## 📄 Description

<b>nelson.unittest.skip</b> marque le test courant comme ignore. <b>skip_testsuite</b> est l'alias de compatibilite.
