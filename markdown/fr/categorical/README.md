# Tableaux categoriels


    
Le module Categorical fournit des tableaux dont les elements appartiennent a un ensemble fixe de categories textuelles.

  

## Functions

- [addcats](addcats.md) - Ajouter des categories a un tableau categoriel.
- [categorical](categorical.md) - Créer un tableau catégoriel.
- [categories](categories.md) - Lister les categories d'un tableau categoriel.
- [combinations](combinations.md) - Generer toutes les combinaisons de valeurs.
- [countcats](countcats.md) - Compter les elements categoriels par categorie.
- [histcounts](histcounts.md) - Compter les valeurs categorielles pour des resumes de type histogramme.
- [iscategorical](iscategorical.md) - Determiner si un tableau est categoriel.
- [iscategory](iscategory.md) - Determiner si des noms sont des categories.
- [isordinal](isordinal.md) - Determiner si un tableau categoriel est ordinal.
- [isprotected](isprotected.md) - Determiner si un tableau categoriel est protege.
- [isundefined](isundefined.md) - Trouver les elements categoriels non definis.
- [mergecats](mergecats.md) - Fusionner des categories dans un tableau categoriel.
- [removecats](removecats.md) - Supprimer des categories d'un tableau categoriel.
- [renamecats](renamecats.md) - Renommer les categories d'un tableau categoriel.
- [reordercats](reordercats.md) - Reordonner les categories d'un tableau categoriel.
- [setcats](setcats.md) - Definir la liste des categories d'un tableau categoriel.
