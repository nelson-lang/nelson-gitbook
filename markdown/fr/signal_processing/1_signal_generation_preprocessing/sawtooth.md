# sawtooth

Signal dent de scie ou triangulaire.

## 📝 Syntaxe

- Y = sawtooth(T)
- Y = sawtooth(T, width)

## 📥 Argument d'entrée

- T - valeurs de temps en radians.
- width - fraction de période montante.

## 📤 Argument de sortie

- Y - valeurs du signal.

## 📄 Description

<b>sawtooth</b> génère une rampe périodique entre -1 et 1.

## 💡 Exemple

```matlab

y = sawtooth(0:0.1:2*pi);

```
