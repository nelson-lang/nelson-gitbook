# sinc

Fonction sinc.

## 📝 Syntaxe

- c = sinc(m)

## 📥 Argument d'entrée

- m - tableau d'entrée : scalaire, vecteur ou matrice.

## 📤 Argument de sortie

- c - sinc de l'entrée

## 📄 Description

<b>c = sinc(m)</b> renvoie un tableau<b>c</b> dont les éléments sont le sinc des éléments de l'entrée : <b>m</b>.

## 💡 Exemple

```matlab
c = sinc(pi)
```
