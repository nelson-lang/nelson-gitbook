# gausswin

Fenêtre gaussienne.

## 📝 Syntaxe

- W = gausswin(M)
- W = gausswin(M, alpha)

## 📥 Argument d'entrée

- M - longueur de la fenêtre.
- alpha - paramètre de forme.

## 📤 Argument de sortie

- W - vecteur colonne contenant la fenêtre.

## 📄 Description

<b>gausswin</b> retourne une fenêtre gaussienne de M points.

## 💡 Exemple

```matlab

w = gausswin(5, 2.5);

```
