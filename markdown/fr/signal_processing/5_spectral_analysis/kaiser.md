# kaiser

Fenêtre de Kaiser.

## 📝 Syntaxe

- W = kaiser(M)
- W = kaiser(M, beta)

## 📥 Argument d'entrée

- M - longueur de la fenêtre.
- beta - paramètre de forme.

## 📤 Argument de sortie

- W - vecteur colonne contenant la fenêtre.

## 📄 Description


<b>kaiser</b> retourne une fenêtre de Kaiser de M points.

## 💡 Exemple



```matlab

w = kaiser(5, 2);

```
