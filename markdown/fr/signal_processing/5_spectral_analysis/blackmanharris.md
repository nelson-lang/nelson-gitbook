# blackmanharris

Fenêtre de Blackman-Harris.

## 📝 Syntaxe

- W = blackmanharris(M)
- W = blackmanharris(M, option)

## 📥 Argument d'entrée

- M - longueur de la fenêtre.
- option - 'symmetric' ou 'periodic'.

## 📤 Argument de sortie

- W - vecteur colonne contenant la fenêtre.

## 📄 Description


<b>blackmanharris</b> retourne une fenêtre de Blackman-Harris à quatre termes.

## 💡 Exemple



```matlab

w = blackmanharris(5);

```
