# rectwin

Fenêtre rectangulaire.

## 📝 Syntaxe

- W = rectwin(M)

## 📥 Argument d'entrée

- M - longueur de la fenêtre.

## 📤 Argument de sortie

- W - vecteur colonne contenant la fenêtre.

## 📄 Description


<b>rectwin</b> retourne une fenêtre rectangulaire de M points.

## 💡 Exemple



```matlab

w = rectwin(4);

```
