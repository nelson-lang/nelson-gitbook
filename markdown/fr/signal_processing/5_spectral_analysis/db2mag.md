# db2mag

Convertit un gain en décibels (dB) en magnitude.

## 📝 Syntaxe

- mag = db2mag(db)

## 📥 Argument d'entrée

- db - tableau d'entrée : scalaire, vecteur ou matrice.

## 📤 Argument de sortie

- mag - magnitude correspondante

## 📄 Description

<b>mag = db2mag(db)</b> renvoie la magnitude correspondante.

## 💡 Exemple

```matlab
mag = db2mag([0, -20])
```
