# triang

Fenêtre triangulaire.

## 📝 Syntaxe

- W = triang(M)

## 📥 Argument d'entrée

- M - longueur de la fenêtre.

## 📤 Argument de sortie

- W - vecteur colonne contenant la fenêtre.

## 📄 Description


<b>triang</b> retourne une fenêtre triangulaire de M points.

## 💡 Exemple



```matlab

w = triang(6);

```
