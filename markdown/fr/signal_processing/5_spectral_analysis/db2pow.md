# db2pow

Convertit un gain en décibels (dB) en puissance.

## 📝 Syntaxe

- pow = db2pow(db)

## 📥 Argument d'entrée

- db - tableau d'entrée : scalaire, vecteur ou matrice.

## 📤 Argument de sortie

- pow - puissance correspondante

## 📄 Description


<b>pow = db2pow(db)</b> renvoie la puissance correspondante.

## 💡 Exemple



```matlab
pow = db2pow([0, -20])
```
