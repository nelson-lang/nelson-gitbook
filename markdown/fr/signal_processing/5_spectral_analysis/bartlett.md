# bartlett

Fenêtre de Bartlett.

## 📝 Syntaxe

- c = bartlett(m)

## 📥 Argument d'entrée

- m - entier positif : longueur de la fenêtre

## 📤 Argument de sortie

- c - vecteur colonne

## 📄 Description


<b>c = bartlett(m)</b> renvoie une fenêtre de Bartlett symétrique de longueur L.

## 📚 Bibliographie

Oppenheim, Alan V., Ronald W. Schafer, and John R. Buck. Discrete-Time Signal Processing. Upper Saddle River, NJ: Prentice Hall, 1999, pp. 468–471.

## 💡 Exemple



```matlab
c = bartlett(8)
```
