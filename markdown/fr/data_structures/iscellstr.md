# iscellstr

Renvoie si une variable est un tableau cellulaire de chaînes.

## 📝 Syntaxe

- true\_or\_false = iscellstr(A)

## 📥 Argument d'entrée

- A - une variable

## 📤 Argument de sortie

- true\_or\_false - un logique

## 📄 Description


<b>iscellstr(A)</b> renvoie vrai si<b>A</b> est un tableau cellulaire de chaînes ou un tableau cellulaire vide.

## 💡 Exemples



```matlab
iscellstr('Nelson')
```


```matlab
iscellstr({'Nelson'})
```


```matlab
iscellstr({})
```
