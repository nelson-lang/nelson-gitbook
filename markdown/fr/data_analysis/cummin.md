# cummin

Minimum cumulatif des elements d'un tableau.

## 📝 Syntaxe

- R = cummin(A)
- R = cummin(A, d)

## 📥 Argument d'entrée

- A - input array.
- d - dimension to operate along: positive integer scalar.

## 📤 Argument de sortie

- R - Cumulative minimum of array elements.

## 📄 Description

<b>cummin</b> renvoie les minimums cumulatifs selon la dimension choisie.

## 💡 Exemple

```matlab
A = [3 1 4 2];
R = cummin(A)
```
