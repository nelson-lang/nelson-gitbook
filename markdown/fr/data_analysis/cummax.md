# cummax

Maximum cumulatif des elements d'un tableau.

## 📝 Syntaxe

- R = cummax(A)
- R = cummax(A, d)

## 📥 Argument d'entrée

- A - input array.
- d - dimension to operate along: positive integer scalar.

## 📤 Argument de sortie

- R - Cumulative maximum of array elements.

## 📄 Description


<b>cummax</b> renvoie les maximums cumulatifs selon la dimension choisie.

## 💡 Exemple



```matlab
A = [3 1 4 2];
R = cummax(A)
```
