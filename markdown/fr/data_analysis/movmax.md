# movmax

Maximum mobile.

## 📝 Syntaxe

- R = movmax(A, window)
- R = movmax(A, window, d)

## 📥 Argument d'entrée

- A - input array.
- window - positive scalar window length.
- d - dimension to operate along: positive integer scalar.

## 📤 Argument de sortie

- R - Moving maximum.

## 📄 Description


<b>movmax</b> calcule les valeurs maximales sur une fenetre mobile centree.

## 💡 Exemple



```matlab
A = [1 2 8 4 5];
R = movmax(A, 3)
```
