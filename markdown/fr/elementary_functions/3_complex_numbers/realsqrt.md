# realsqrt

Racine carree avec resultat reel uniquement.

## 📝 Syntaxe

- R = realsqrt(X)

## 📥 Argument d'entrée

- X - input array.

## 📤 Argument de sortie

- R - Square root with real-only result.

## 📄 Description

<b>realsqrt</b> calcule sqrt(X) et renvoie une erreur si une entree ou le resultat est complexe.

## 💡 Exemple

```matlab
x = [1 4 9];
R = realsqrt(x)
```
