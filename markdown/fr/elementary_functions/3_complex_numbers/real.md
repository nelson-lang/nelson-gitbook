# real

Partie réelle d'un nombre complexe.

## 📝 Syntaxe

- R = real(M)

## 📥 Argument d'entrée

- M - une variable

## 📤 Argument de sortie

- R - partie réelle des éléments du tableau complexe M.

## 📄 Description

<b>R = real(M)</b> renvoie la partie réelle de M.

## 💡 Exemple

```matlab
cplx = 22+34*i;
r = real(cplx)
```
