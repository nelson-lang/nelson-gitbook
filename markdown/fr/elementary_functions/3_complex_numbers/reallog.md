# reallog

Logarithme naturel avec resultat reel uniquement.

## 📝 Syntaxe

- R = reallog(X)

## 📥 Argument d'entrée

- X - input array.

## 📤 Argument de sortie

- R - Natural logarithm with real-only result.

## 📄 Description


<b>reallog</b> calcule log(X) et renvoie une erreur si une entree ou le resultat est complexe.

## 💡 Exemple



```matlab
x = [1 2 4];
R = reallog(x)
```
