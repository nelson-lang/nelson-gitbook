# flipud

Inverser l'ordre des éléments de haut en bas

## 📝 Syntaxe

- B = flipud(A)

## 📥 Argument d'entrée

- A - un tableau

## 📤 Argument de sortie

- B - tableau inversé.

## 📄 Description

<b>flipud</b> renvoie un nouveau tableau de <b>A</b> inversé de haut en bas.

## 💡 Exemple

```matlab
x = eye(3, 2);
y = flipud(x)
```
