# isscalar

Tester si l'entrée est un scalaire

## 📝 Syntaxe

- TF = iscalar(A)

## 📥 Argument d'entrée

- A - une variable

## 📤 Argument de sortie

- res - résultat booléen

## 📄 Description

<b>isscalar</b> renvoie <b>TRUE</b> si l'entrée est un scalaire.

## 💡 Exemple

```matlab
x = [1+i, -i ; i, 2i];
isscalar(x)
isscalar(1)
```
