# numel

Nombre d'éléments.

## 📝 Syntaxe

- nbel = numel(M)

## 📥 Argument d'entrée

- M - une variable

## 📤 Argument de sortie

- nbel - le nombre d'éléments.

## 📄 Description

Renvoie le nombre d'éléments de l'objet M.

## 💡 Exemple

```matlab
numel(ones(3, 0))
numel(ones(3,4))
numel(ones(3,4,5))
```
