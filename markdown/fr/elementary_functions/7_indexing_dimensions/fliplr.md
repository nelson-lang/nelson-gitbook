# fliplr

Inverser l'ordre des éléments de gauche à droite

## 📝 Syntaxe

- B = fliplr(A)

## 📥 Argument d'entrée

- A - un tableau

## 📤 Argument de sortie

- B - tableau inversé.

## 📄 Description


<b>fliplr</b> renvoie un nouveau tableau de <b>A</b> inversé de gauche à droite.

## 💡 Exemple



```matlab
x = eye(3, 2);
y = fliplr(x)
```
