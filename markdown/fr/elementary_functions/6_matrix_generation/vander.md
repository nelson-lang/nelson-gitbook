# vander

Matrice de Vandermonde

## 📝 Syntaxe

- A = vander(v)

## 📥 Argument d'entrée

- v - un vecteur numérique.

## 📤 Argument de sortie

- A - matrice de Vandermonde.

## 📄 Description


<b>A = vander(v)</b> renvoie la matrice de Vandermonde.

## 📚 Bibliographie

https://en.wikipedia.org/wiki/Vandermonde_matrix

## 💡 Exemple



```matlab
A = vander(1:.5:3)
```
