# bin2dec

Convertit un nombre en base 2 en décimal.

## 📝 Syntaxe

- D = bin2dec(TXT)

## 📥 Argument d'entrée

- TXT - un tableau de caractères.

## 📤 Argument de sortie

- D - résultat de bin2dec : une valeur entière.

## 📄 Description


<b>bin2dec</b> convertit un nombre en base 2 en décimal. 

Remarque : <b>bin2dec</b> et<b>dec2bin</b> sont des opérations réciproques.

## 💡 Exemple



```matlab
bin2dec('11')
```
