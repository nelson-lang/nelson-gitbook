# hex2dec

Convertit un nombre en base 16 en décimal.

## 📝 Syntaxe

- D = hex2dec(TXT)

## 📥 Argument d'entrée

- TXT - un tableau de caractères.

## 📤 Argument de sortie

- D - résultat de hex2dec : une valeur entière.

## 📄 Description

<b>hex2dec</b> convertit un nombre en base 16 en décimal.

Remarque : <b>hex2dec</b> et<b>dec2hex</b> sont des opérations réciproques.

## 💡 Exemple

```matlab
bin2dec('11')
```
