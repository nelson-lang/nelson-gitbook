# num2bin

Convertit un nombre en sa représentation binaire.

## 📝 Syntaxe

- R = num2bin(M)

## 📥 Argument d'entrée

- M - une variable : matrice pleine réelle logique, entière, single ou double.

## 📤 Argument de sortie

- R - résultat de num2bin : tableau de caractères.

## 📄 Description


<b>num2bin</b> renvoie un tableau de caractères donnant la représentation binaire littérale d'un nombre.

## Fonction(s) utilisée(s)

C++ std::bitset

## 📚 Bibliographie

http://www.oxfordmathcenter.com/drupal7/node/43

## 💡 Exemple



```matlab
X = [65535 128; 1 0]
Y = num2bin(X)
```
