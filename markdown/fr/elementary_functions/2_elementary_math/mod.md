# mod

Modulo après division.

## 📝 Syntaxe

- C = mod(A, B)

## 📥 Argument d'entrée

- A - une variable : dividende
- B - une variable : diviseur

## 📤 Argument de sortie

- C - résultat de mod(A, B)

## 📄 Description

<b>C = mod(A, B)</b> calcule le modulo de A et B, c'est-à-dire : A - B .\* floor (A ./ B).

Cette fonction gère également les valeurs négatives.

## 💡 Exemple

```matlab
 mod (-1, 3)
```
