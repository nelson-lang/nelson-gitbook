# log1p

log(1 + x) avec précision pour de petites valeurs de x.

## 📝 Syntaxe

- R = log1p(M)

## 📥 Argument d'entrée

- M - une variable

## 📤 Argument de sortie

- R - résultat de log(1 + x) calculé avec précision pour de petites valeurs de x.

## 📄 Description

<b>log1p</b> calcule log(1 + x) avec précision pour de petites valeurs de x.

## 💡 Exemple

```matlab
x = [1+i,-i;i,2i];
r = log1p(x)
```
