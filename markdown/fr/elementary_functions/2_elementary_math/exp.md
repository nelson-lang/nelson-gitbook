# exp

Exponentielle

## 📝 Syntaxe

- R = exp(M)

## 📥 Argument d'entrée

- M - une variable

## 📤 Argument de sortie

- R - résultat de exp : exponentielle.

## 📄 Description


<b>exp</b> calcule la fonction exponentielle. 

Pour les nombres réels : 
$$e^x$$
 

Pour les nombres complexes <b>z = x + iy</b> : 
$$e^z = e^x(\cos y + i\sin y)$$


## 💡 Exemple



```matlab
x = [1+i,-i;i,2i];
r = exp(x)
```
