# log10

Logarithme décimal (base 10).

## 📝 Syntaxe

- R = log10(M)

## 📥 Argument d'entrée

- M - une variable

## 📤 Argument de sortie

- R - résultat de log : base 10.

## 📄 Description

<b>log10</b> calcule le logarithme décimal (base 10).

Pour les valeurs réelles négatives et les valeurs complexes de M, la fonction<b>log10</b> renvoie des valeurs complexes.

## 💡 Exemple

```matlab
x = [1+i,-i;i,2i];
r = log10(x)
```
