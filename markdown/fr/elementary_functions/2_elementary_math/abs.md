# abs

Valeur absolue

## 📝 Syntaxe

- R = abs(M)

## 📥 Argument d'entrée

- M - une variable

## 📤 Argument de sortie

- R - résultat de abs : valeur absolue.

## 📄 Description

<b>abs</b> calcule la valeur absolue.

Si l'argument est un nombre complexe, <b>abs</b> calcule la magnitude complexe.

## 💡 Exemple

```matlab
x = [1+i,-i;i,2i];
r = abs(x)
```
