# log

Logarithme naturel.

## 📝 Syntaxe

- R = log(M)

## 📥 Argument d'entrée

- M - une variable

## 📤 Argument de sortie

- R - résultat de log : logarithme naturel.

## 📄 Description

<b>log</b> calcule le logarithme naturel.

Pour les nombres réels positifs :
$$\ln(x)$$

Pour les nombres complexes <b>z</b> :
$$\ln(z) = \ln|z| + i\arg(z)$$

où
$$|z|$$

est le module et
$$\arg(z)$$

est l'argument de <b>z</b>.

## 💡 Exemple

```matlab
x = [1+i,-i;i,2i];
r = log(x)
```
