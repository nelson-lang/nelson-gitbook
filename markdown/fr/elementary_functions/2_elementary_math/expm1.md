# expm1

Calcule exp(x) - 1.

## 📝 Syntaxe

- R = expm1(X)

## 📥 Argument d'entrée

- X - input array.

## 📤 Argument de sortie

- R - Compute exp(x) - 1.

## 📄 Description


<b>expm1</b> calcule exp(X) - 1 element par element.

## 💡 Exemple



```matlab
x = [-1 0 1];
R = expm1(x)
```
