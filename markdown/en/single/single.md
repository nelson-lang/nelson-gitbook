# single

Converts a variable to single precision type.

## 📝 Syntax

- S = single(V)

## 📥 Input argument

- V - a variable.

## 📤 Output argument

- S - a single.

## 📄 Description


<b>single(V)</b> converts to the single-precision type.

## 💡 Examples



```matlab
single('Nelson')
```


```matlab
A = single(pi)
```
