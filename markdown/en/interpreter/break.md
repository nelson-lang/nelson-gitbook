# break

exit evaluation loop.

## 📝 Syntax

- break

## 📄 Description


<b>break</b> statement is used to exit a loop prematurely. 

<b>break</b> statement can be used inside a <b>for</b> or a<b>while</b> loop.

## 💡 Example



```matlab

for i = 1:10
  if i == 5
   disp('i == 5');
   break;
  end
  disp(i)
end

```
