# while

while loop.

## 📝 Syntax

- while test\_expression, statements, end

## 📄 Description


<b>while</b> loop executes a set of statements as long as a the test condition remains<b>true</b>.

## 💡 Example



```matlab

i = 0;
while lt(i, 10)
  disp(i)
  i = i + 1;
end

```
