# nelsonroot

Returns Nelson's root folder.

## 📝 Syntax

- nelson\_path = nelsonroot

## 📤 Output argument

- nelson\_path - a string: the root folder of Nelson.

## 📄 Description


<b>nelsonroot</b> returns the root folder of Nelson.

## 💡 Example



```matlab
pwd
cd(nelsonroot)
pwd
```
