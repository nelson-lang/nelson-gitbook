# prefdir

Return the preferences directory used by Nelson.

## 📝 Syntax

- pref\_path = prefdir

## 📤 Output argument

- pref\_path - a string: the preferences directory

## 📄 Description


<b>pref\_path = prefdir()</b> returns the preferences directory used by Nelson.

## 💡 Example

an example

```matlab
cd(prefdir)
```
