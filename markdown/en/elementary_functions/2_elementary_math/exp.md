# exp

Exponential

## 📝 Syntax

- R = exp(M)

## 📥 Input argument

- M - a variable

## 📤 Output argument

- R - result of exp: exponential.

## 📄 Description


<b>exp</b> computes the exponential value. 

For real numbers: 
$$e^x$$
 

For complex numbers <b>z = x + iy</b>: 
$$e^z = e^x(\cos y + i\sin y)$$


## 💡 Example



```matlab
x = [1+i,-i;i,2i];
r = exp(x)
```
