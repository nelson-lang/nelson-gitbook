# rat

Rational fraction approximation.

## 📝 Syntax

- [N, D] = rat(X)
- [N, D] = rat(X, tol)
- S = rat(X)
- S = rat(X, tol)

## 📥 Input argument

- X - Input array: real or complex, scalar, vector or matrix (single or double).
- tol - Tolerance: scalar. The default is <b>1e-6 \* norm(X(:), 1)</b>.

## 📤 Output argument

- N - Numerator: array of the same size as <b>X</b>, or the continued fraction character array when a single output is requested.
- D - Denominator: array of the same size as <b>X</b>.

## 📄 Description


<b>[N, D] = rat(X)</b> returns two integer arrays so that <b>N ./ D</b> is close to <b>X</b> in the sense that <b>abs(N ./ D - X) <= tol</b>. 

The rational approximations are generated by truncating continued fraction expansions. 

<b>S = rat(X)</b> returns the continued fraction representation as a character array.

## 💡 Example



```matlab
[N, D] = rat(pi)
S = rat(pi)
```
