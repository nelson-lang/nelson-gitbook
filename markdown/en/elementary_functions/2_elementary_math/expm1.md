# expm1

Compute exp(x) - 1.

## 📝 Syntax

- R = expm1(X)

## 📥 Input argument

- X - input array.

## 📤 Output argument

- R - Compute exp(x) - 1.

## 📄 Description


<b>expm1</b> computes exp(X) - 1 element by element.

## 💡 Example



```matlab
x = [-1 0 1];
R = expm1(x)
```
