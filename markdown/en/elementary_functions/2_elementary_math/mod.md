# mod

Modulus after division.

## 📝 Syntax

- C = mod(A, B)

## 📥 Input argument

- A - a variable: dividend
- B - a variable: divisor

## 📤 Output argument

- C - result of mod(A, B)

## 📄 Description


<b>C = mod(A, B)</b> computes the modulo of A and B, i.e : A - B .\* floor (A ./ B). 

This function manages also negative values.

## 💡 Example



```matlab
 mod (-1, 3)
```
