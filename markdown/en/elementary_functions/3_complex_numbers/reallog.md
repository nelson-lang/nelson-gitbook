# reallog

Natural logarithm with real-only result.

## 📝 Syntax

- R = reallog(X)

## 📥 Input argument

- X - input array.

## 📤 Output argument

- R - Natural logarithm with real-only result.

## 📄 Description

<b>reallog</b> computes log(X) and returns an error if an input or the result is complex.

## 💡 Example

```matlab
x = [1 2 4];
R = reallog(x)
```
