# realsqrt

Square root with real-only result.

## 📝 Syntax

- R = realsqrt(X)

## 📥 Input argument

- X - input array.

## 📤 Output argument

- R - Square root with real-only result.

## 📄 Description

<b>realsqrt</b> computes sqrt(X) and returns an error if an input or the result is complex.

## 💡 Example

```matlab
x = [1 4 9];
R = realsqrt(x)
```
