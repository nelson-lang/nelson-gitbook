# numel

Number of elements.

## 📝 Syntax

- nbel = numel(M)

## 📥 Input argument

- M - a variable

## 📤 Output argument

- nbel - the number of elements.

## 📄 Description


Return the number of elements in the object M.

## 💡 Example



```matlab
numel(ones(3, 0))
numel(ones(3,4))
numel(ones(3,4,5))
```
