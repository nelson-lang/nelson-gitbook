# median

Median value of array elements.

## 📝 Syntax

- R = median(M)
- R = median(M, d)
- R = median(M, 'all')
- R = median(..., 'omitnan')

## 📄 Description


<b>median</b> returns the middle value of sorted data along the selected dimension.

## 💡 Example


```matlab
R = median([4 1 2 3])
```
