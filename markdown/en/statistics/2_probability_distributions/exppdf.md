# exppdf

Exponential probability density function

## 📝 Syntax

- y = exppdf(x)
- y = exppdf(x, mu)

## 📥 Input argument

- x - real numeric array.
- mu - positive mean parameter, default 1.

## 📤 Output argument

- y - probability density values.

## 📄 Description


<b>exppdf</b> computes exponential distribution density values.

## 💡 Example



```matlab
x = [0 0.5 1 2];
y = exppdf(x, 3);
```
