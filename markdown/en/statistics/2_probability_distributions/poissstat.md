# poissstat

Poisson mean and variance

## 📝 Syntax

- [m, v] = poissstat(lambda)

## 📥 Input argument

- lambda - nonnegative scalar or array: rate parameter.

## 📤 Output argument

- m - array: mean values.
- v - array: variance values.

## 📄 Description

<b>poissstat</b> returns the mean and variance of the Poisson distribution.

## 💡 Example

```matlab
[m, v] = poissstat([0 1 5]);
```
