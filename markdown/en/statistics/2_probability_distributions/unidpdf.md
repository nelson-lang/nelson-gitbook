# unidpdf

Discrete uniform probability density function

## 📝 Syntax

- y = unidpdf(x, n)

## 📥 Input argument

- x - real numeric array.
- n - positive integer scalar or array: maximum value.

## 📤 Output argument

- y - probability values.

## 📄 Description


<b>unidpdf</b> computes probabilities for the discrete uniform distribution on integers from 1 to <b>n</b>.

## 💡 Example



```matlab
x = 0:6;
y = unidpdf(x, 5);
```
