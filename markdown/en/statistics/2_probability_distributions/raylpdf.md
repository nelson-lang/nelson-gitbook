# raylpdf

Rayleigh probability density function

## 📝 Syntax

- y = raylpdf(x, b)

## 📥 Input argument

- x - real scalar or array: values.
- b - positive scalar or array: scale parameter.

## 📤 Output argument

- y - array: density values.

## 📄 Description


<b>raylpdf</b> evaluates Rayleigh probability density values element by element.

## 💡 Example



```matlab
x = [0 2 4];
y = raylpdf(x, 2);
```
