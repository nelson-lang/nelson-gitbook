# radtodeg

Convert angle from radians to degrees.

## 📝 Syntax

- d = radtodeg(r)

## 📥 Input argument

- r - a numeric value (double or single)

## 📤 Output argument

- d - a numeric value

## 📄 Description
<b>d = radtodeg(r)</b> converts angle units from radians to degrees for each element of <b>r</b>.

## 💡 Example



```matlab
dist = 7194;
radEarth = 6371;
D = radtodeg(dist / radEarth)
```
