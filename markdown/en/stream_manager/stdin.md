# stdin

File identifier of the standard input stream.

## 📝 Syntax

- fd = stdin()

## 📤 Output argument

- fd - the value <b>0</b>.

## 📄 Description


<b>fd = stdin()</b> returns <b>0</b>, the file identifier of the standard input stream.

## 💡 Example



```matlab
fd = stdin()
```
