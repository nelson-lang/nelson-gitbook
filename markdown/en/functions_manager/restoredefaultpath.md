# restoredefaultpath

Restore Nelson’s path to its initial state at startup.

## 📝 Syntax

- restoredefaultpath

## 📄 Description


<b>restoredefaultpath</b> restores Nelson's search path to its startup state.

## 💡 Example



```matlab
path
path('')
path
restoredefaultpath
path
```
