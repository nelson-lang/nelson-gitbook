# what

Get Nelson builtin and macro list.

## 📝 Syntax

- list\_builtin = what()
- [list\_builtin, list\_macro] = what()

## 📤 Output argument

- list\_builtin - a cell of strings
- list\_macro - a cell of strings

## 📄 Description


<b>what</b> returns the list of all builtin and macro available in current Nelson's session.

## 💡 Example



```matlab
l = what()
[l, m] = what()
```
