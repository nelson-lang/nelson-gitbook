# iscellstr

Returns if a variable is a cell of strings.

## 📝 Syntax

- true\_or\_false = iscellstr(A)

## 📥 Input argument

- A - a variable

## 📤 Output argument

- true\_or\_false - a logical

## 📄 Description


<b>iscellstr(A)</b> returns true if <b>A</b> is a cell of strings or an empty cell).

## 💡 Examples



```matlab
iscellstr('Nelson')
```


```matlab
iscellstr({'Nelson'})
```


```matlab
iscellstr({})
```
