# Notebook


    
The Notebook module runs Notebook documents outside the editor.

    
A Notebook mixes formatted text, code and its output in one document. This module reads the native **.nlx** container and the plain-text **.m** Notebook format, and executes their code cells against the base workspace — so a document can be run from the command line or a script.

    
Three step-by-step tutorials cover creating your first Notebook, its cells and controls, and how to run and share a document.

  

## Functions

- [Your first Nelson Notebook](1_notebook_first_steps.md) - Create, run and save your first Notebook document.
- [Notebook cells and controls](2_notebook_cells_and_controls.md) - The block kinds of a Notebook and the interactive controls.
- [Run and share a Notebook](3_notebook_run_and_share.md) - Run a Notebook without the editor, and export or import it.
- [nlx](nlx.md) - The Nelson Notebook document format (.nlx).
- [notebook](notebook.md) - Run a Notebook document or open the Notebook editor.
