# Text editor


    
The Text Editor module provides an embedded Nelson editor for creating, editing, and formatting Nelson scripts and files.

  

## Functions

- [debugging workflow](debugging_workflow.md) - Debugging workflow for Nelson code files in the editor.
- [edit](edit.md) - function editor.
- [editor](editor.md) - call the embedded text editor.
- [opentoline](opentoline.md) - opens a file in the editor at a line.
