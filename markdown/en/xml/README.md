# Xml Processing

The XML module provides functions to create, convert, and manage XML documents for Nelson.

## Functions

- [readstruct](readstruct.md) - Read XML data as a structure
- [writestruct](writestruct.md) - Write a structure as XML
- [xmlchecker](xmlchecker.md) - Checks a xmlfile against xsd.
- [xmlprettyprint](xmlprettyprint.md) - format an XML file.
- [xmlread](xmlread.md) - Read an XML file as a document object
- [xmltransform](xmltransform.md) - XML transformation using XSLT
- [xmlwrite](xmlwrite.md) - Serialize an XML document object
- [xslt](xslt.md) - Transform XML using XSLT
