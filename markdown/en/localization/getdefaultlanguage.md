# getdefaultlanguage

Returns the default language used in Nelson.

## 📝 Syntax

- lang = getdefaultlanguage()

## 📤 Output argument

- lang - a string: 'en\_US' by default.

## 📄 Description


<b>getdefaultlanguage</b> returns the default language used by Nelson.

## 💡 Example



```matlab
getdefaultlanguage()
```
