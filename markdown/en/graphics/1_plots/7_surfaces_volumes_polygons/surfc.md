# surfc

Display a surface with contour lines below it.

## 📝 Syntax

- surfc(Z)
- surfc(X, Y, Z)
- surfc(parent, ...)
- h = surfc(...)

## 📄 Description

<b>surfc</b> displays a surface and contour lines projected at the base of the surface.

## 💡 Example

Surface with contours.

```matlab
surfc(peaks(30));
```
