# shg

Show the current graph window.

## 📝 Syntax

- shg
- shg()

## 📄 Description


<b>shg</b> brings the current figure forward, creating one if none exists. It is equivalent to <b>figure(gcf)</b>.

## 💡 Example



```matlab
f = figure();
plot(1:10);
shg
```
