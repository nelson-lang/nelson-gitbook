# newplot

Prepare to produce a new plot.

## 📝 Syntax

- go = newplot()
- go = newplot(ax)

## 📥 Input argument

- ax - specified figure or axes rather than the current figure and axes.

## 📤 Output argument

- go - a graphics object: axes type.

## 📄 Description

<b>newplot</b> prepares a figure and axes for graphics commands.

## 💡 Example

```matlab
h = newplot()
```
