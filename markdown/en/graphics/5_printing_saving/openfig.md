# openfig

Open a Nelson FIG file.

## 📝 Syntax

- openfig()
- openfig(filename)
- openfig(filename, copies)
- openfig(filename, visibility)
- openfig(filename, copies, visibility)
- fig = openfig(...)

## 📥 Input argument

- filename - Character vector or string scalar naming a Nelson <b>.fig</b> file. If filename has no extension, <b>openfig</b> appends <b>.fig</b>. The default is <b>Untitled.fig</b>.
- copies - <b>'new'</b> or <b>'reuse'</b>. The default is <b>'new'</b>. Use <b>'reuse'</b> to return an already opened figure whose <b>FileName</b> property matches the requested file.
- visibility - <b>'visible'</b> or <b>'invisible'</b>. This option overrides the saved visible state after the figure is restored or reused.

## 📤 Output argument

- fig - Opened figure graphics object or array of figure graphics objects. If the file contains several saved figures, all restored figures are returned.

## 📄 Description

<b>openfig()</b> opens <b>Untitled.fig</b>.

<b>openfig(filename)</b> opens the figure or figures stored in <b>filename</b> and creates new figure objects.

<b>openfig(filename, 'new')</b> always creates new figure objects. This is the default behavior.

<b>openfig(filename, 'reuse')</b> first searches opened figures whose <b>FileName</b> property matches the resolved file path. If such figures exist, they are returned instead of loading a new copy.

<b>openfig(filename, visibility)</b> or <b>openfig(filename, copies, visibility)</b> controls whether restored or reused figures are visible.

Each restored figure receives a <b>FileName</b> property equal to the resolved <b>.fig</b> path. This allows later calls with <b>'reuse'</b> to find it.

<b>Warning:</b> Nelson <b>.fig</b> files are Nelson-specific. Files not generated by Nelson are not supported.

The restored objects are new graphics objects. Most persistent properties saved by <b>savefig</b> are restored, while current defaults and runtime-only state can still affect the newly created figures.

## 💡 Examples

Save a figure, close it, and reopen it later.

```matlab

x = linspace(0, 10);
y = sin(x);
f = figure('Visible', 'off');
plot(x, y);
title('Sine Wave');
xlabel('x ranges from 0 to 10');
ylabel('y = sin(x)');
figfile = [tempname(), '_SineWave.fig'];
savefig(f, figfile);
close(f);
restored = openfig(figfile, 'invisible');
assert(isgraphics(restored, 'figure'));
close(restored);

```

Open a saved invisible figure in visible state.

```matlab

f = figure('Visible', 'off');
plot(1:5);
figfile = [tempname(), '_visible_on_open.fig'];
savefig(f, figfile);
close(f);
restored = openfig(figfile, 'visible');
assert(strcmp(char(get(restored, 'Visible')), 'on'));
close(restored);

```

Reuse an already opened figure.

```matlab

f = figure('Visible', 'off');
plot([3 1 4 1 5]);
figfile = [tempname(), '_reuse_example.fig'];
savefig(f, figfile);
close(f);
first = openfig(figfile, 'invisible');
second = openfig(figfile, 'reuse', 'invisible');
assert(isequal(first, second));
close(first);

```

Open a file containing several figures.

```matlab

figs(1) = figure('Visible', 'off');
plot(1:4);
figs(2) = figure('Visible', 'off');
stairs([4 2 3]);
figfile = [tempname(), '_many_figures.fig'];
savefig(figs, figfile);
close(figs);
restored = openfig(figfile, 'invisible');
assert(isequal(numel(restored), 2));
close(restored);

```
