# refresh

Redraw current figure.

## 📝 Syntax

- refresh()
- refresh(F)

## 📥 Input argument

- F - figure graphics object.

## 📄 Description

<b>refresh</b> erases and redraws the current figure.

<b>refresh(F)</b> redraws the figure identified by <b>F</b>.
