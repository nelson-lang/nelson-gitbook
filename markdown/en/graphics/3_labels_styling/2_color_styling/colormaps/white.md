# white

white colormap array.

## 📝 Syntax

- c = white
- c = white(m)

## 📥 Input argument

- m - a scalar integer value: Number of colors (256 as default value).

## 📤 Output argument

- c - White colormap array.

## 📄 Description


<b>white</b> returns the colormap with white colors.

## 💡 Example



```matlab
f = figure();
surf(peaks);
colormap('white');
```
