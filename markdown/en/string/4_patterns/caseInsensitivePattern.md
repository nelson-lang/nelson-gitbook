# caseInsensitivePattern

Match pattern ignoring case.

## 📝 Syntax

- R = caseInsensitivePattern(...)

## 📄 Description

<b>caseInsensitivePattern</b> Match pattern ignoring case.

## 💡 Example

```matlab
pat = caseInsensitivePattern("nelson"); extract("Nelson", pat)
```
