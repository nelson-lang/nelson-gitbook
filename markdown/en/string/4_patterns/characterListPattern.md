# characterListPattern

Pattern for listed characters.

## 📝 Syntax

- R = characterListPattern(...)

## 📄 Description

<b>characterListPattern</b> Pattern for listed characters.

## 💡 Example

```matlab
pat = characterListPattern("a", "c"); extract("abc123", pat)
```
