# digitBoundary

Boundary for digit text.

## 📝 Syntax

- R = digitBoundary(...)

## 📄 Description


<b>digitBoundary</b> Boundary for digit text.

## 💡 Example



```matlab
pat = digitBoundary("start") + digitsPattern(3); extract("ID123 A45", pat)
```
