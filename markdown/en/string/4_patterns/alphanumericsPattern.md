# alphanumericsPattern

Pattern for alphanumeric characters.

## 📝 Syntax

- R = alphanumericsPattern(...)

## 📄 Description

<b>alphanumericsPattern</b> Pattern for alphanumeric characters.

## 💡 Example

```matlab
pat = alphanumericsPattern; extract("A1 !", pat)
```
