# namedPattern

Named pattern.

## 📝 Syntax

- R = namedPattern(...)

## 📄 Description

<b>namedPattern</b> Named pattern.

## 💡 Example

```matlab
pat = namedPattern(digitsPattern(3), "code"); extract("code 123", pat)
```
