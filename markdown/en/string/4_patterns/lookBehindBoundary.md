# lookBehindBoundary

Boundary after a pattern.

## 📝 Syntax

- R = lookBehindBoundary(...)

## 📄 Description


<b>lookBehindBoundary</b> Boundary after a pattern.

## 💡 Example



```matlab
pat = lookBehindBoundary("abc") + digitsPattern(3); extract("abc123", pat)
```
