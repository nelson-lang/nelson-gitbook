# letterBoundary

Boundary for letter text.

## 📝 Syntax

- R = letterBoundary(...)

## 📄 Description

<b>letterBoundary</b> Boundary for letter text.

## 💡 Example

```matlab
pat = letterBoundary("start") + lettersPattern(3); extract("123abc", pat)
```
