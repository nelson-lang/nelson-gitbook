# possessivePattern

Match pattern possessively.

## 📝 Syntax

- R = possessivePattern(...)

## 📄 Description


<b>possessivePattern</b> Match pattern possessively.

## 💡 Example



```matlab
pat = possessivePattern("a"); char(pat)
```
