# whitespacePattern

Pattern for whitespace characters.

## 📝 Syntax

- R = whitespacePattern(...)

## 📄 Description

<b>whitespacePattern</b> Pattern for whitespace characters.

## 💡 Example

```matlab
pat = whitespacePattern; extract("a b", pat)
```
