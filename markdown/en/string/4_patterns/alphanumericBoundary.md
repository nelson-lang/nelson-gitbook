# alphanumericBoundary

Boundary for alphanumeric text.

## 📝 Syntax

- R = alphanumericBoundary(...)

## 📄 Description

<b>alphanumericBoundary</b> Boundary for alphanumeric text.

## 💡 Example

```matlab
pat = alphanumericBoundary("start") + alphanumericsPattern(3); extract("ID A12", pat)
```
