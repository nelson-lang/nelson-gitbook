# asManyOfPattern

Repeat pattern as many times as possible.

## 📝 Syntax

- R = asManyOfPattern(...)

## 📄 Description


<b>asManyOfPattern</b> Repeat pattern as many times as possible.

## 💡 Example



```matlab
pat = asManyOfPattern("b"); extract("abbbc", "a" + pat + "c")
```
