# maskedPattern

Pattern with display name.

## 📝 Syntax

- R = maskedPattern(...)

## 📄 Description


<b>maskedPattern</b> Pattern with display name.

## 💡 Example



```matlab
pat = maskedPattern(digitsPattern(3), "area code"); extract("phone 123", pat)
```
