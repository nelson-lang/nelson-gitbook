# asFewOfPattern

Repeat pattern as few times as possible.

## 📝 Syntax

- R = asFewOfPattern(...)

## 📄 Description


<b>asFewOfPattern</b> Repeat pattern as few times as possible.

## 💡 Example



```matlab
pat = asFewOfPattern("b"); extract("abbbc", "a" + pat + "c")
```
