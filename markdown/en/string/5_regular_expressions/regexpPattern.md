# regexpPattern

Pattern from regular expression.

## 📝 Syntax

- R = regexpPattern(...)

## 📄 Description

<b>regexpPattern</b> Pattern from regular expression.

## 💡 Example

```matlab
pat = regexpPattern('\d+'); extract("abc123", pat)
```
