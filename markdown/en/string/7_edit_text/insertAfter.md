# insertAfter

Insert text after a boundary.

## 📝 Syntax

- R = insertAfter(...)

## 📄 Description


<b>insertAfter</b> Insert text after a boundary.

## 💡 Example



```matlab
insertAfter("a=b", "=", "1")
```
