# insertBefore

Insert text before a boundary.

## 📝 Syntax

- R = insertBefore(...)

## 📄 Description

<b>insertBefore</b> Insert text before a boundary.

## 💡 Example

```matlab
insertBefore("a=b", "=", "1")
```
