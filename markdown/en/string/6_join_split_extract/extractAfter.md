# extractAfter

Extract text after a boundary.

## 📝 Syntax

- R = extractAfter(...)

## 📄 Description

<b>extractAfter</b> Extract text after a boundary.

## 💡 Example

```matlab
extractAfter("abc.def", ".")
```
