# extractBefore

Extract text before a boundary.

## 📝 Syntax

- R = extractBefore(...)

## 📄 Description

<b>extractBefore</b> Extract text before a boundary.

## 💡 Example

```matlab
extractBefore("abc.def", ".")
```
