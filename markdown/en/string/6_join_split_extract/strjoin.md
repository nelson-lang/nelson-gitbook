# strjoin

Join text with a delimiter.

## 📝 Syntax

- R = strjoin(...)

## 📄 Description


<b>strjoin</b> Join text with a delimiter.

## 💡 Example



```matlab
strjoin(["a", "b", "c"], ",")
```
