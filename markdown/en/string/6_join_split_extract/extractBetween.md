# extractBetween

Extract text between boundaries.

## 📝 Syntax

- R = extractBetween(...)

## 📄 Description


<b>extractBetween</b> Extract text between boundaries.

## 💡 Example



```matlab
extractBetween("a[bc]d", "[", "]")
```
