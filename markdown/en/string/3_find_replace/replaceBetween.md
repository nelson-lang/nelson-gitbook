# replaceBetween

Replace text between boundaries.

## 📝 Syntax

- R = replaceBetween(...)

## 📄 Description

<b>replaceBetween</b> Replace text between boundaries.

## 💡 Example

```matlab
replaceBetween("a[old]b", "[", "]", "new")
```
