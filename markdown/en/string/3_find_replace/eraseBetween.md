# eraseBetween

Erase text between boundaries.

## 📝 Syntax

- R = eraseBetween(...)

## 📄 Description


<b>eraseBetween</b> Erase text between boundaries.

## 💡 Example



```matlab
eraseBetween("a[secret]b", "[", "]")
```
