# strmatch

Find strings that start with text.

## 📝 Syntax

- R = strmatch(...)

## 📄 Description


<b>strmatch</b> Find strings that start with text.

## 💡 Example



```matlab
strmatch("max", ["max"; "min"; "maximum"])
```
