# convertContainedStringsToChars

Convert contained string arrays to character vectors.

## 📝 Syntax

- R = convertContainedStringsToChars(...)

## 📄 Description

<b>convertContainedStringsToChars</b> Convert contained string arrays to character vectors.

## 💡 Example

```matlab
C = convertContainedStringsToChars({"one", "two"})
```
