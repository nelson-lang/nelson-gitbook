# qml\_loadfile

Load a QML file.

## 📝 Syntax

- h = qml\_loadfile(filename)

## 📥 Input argument

- filename - a string: a QML filename.

## 📤 Output argument

- h - a QObject handle.

## 📄 Description


Load a QML file 

It creates a QML component and load .qml file.
