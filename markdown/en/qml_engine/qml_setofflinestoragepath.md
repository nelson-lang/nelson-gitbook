# qml\_setofflinestoragepath

Set the Property contains the directory to store offline user data.

## 📝 Syntax

- qml\_setofflinestoragepath(path\_data)

## 📥 Input argument

- path\_data - a string

## 📄 Description


Set the Property contains the directory to store offline user data.

## 💡 Example



```matlab
qml_setofflinestoragepath(tmpdir())
 
```
