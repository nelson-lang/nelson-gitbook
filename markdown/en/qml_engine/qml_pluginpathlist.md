# qml\_pluginpathlist

Returns the list of directories where the engine searches for native plugins for imported modules.

## 📝 Syntax

- p = qml\_pluginpathlist()

## 📤 Output argument

- p - a string: path.

## 📄 Description


Returns the list of directories where the engine searches for native plugins for imported modules.

## 💡 Example



```matlab
qml_pluginpathlist()
```
