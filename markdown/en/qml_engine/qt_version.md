# qt\_version

Returns Qt version used.

## 📝 Syntax

- v = qt\_version()

## 📤 Output argument

- v - a string : valid path.

## 📄 Description


<b>v = qt\_version()</b> returns the version number of Qt at run-time as a string (for example, "6.2.4").

## 💡 Example



```matlab
semver(qt_version(), '>=6.2')
```
