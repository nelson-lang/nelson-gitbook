# QObject\_undefine

Undefine a dynamic property of a QObject handle.

## 📝 Syntax

- QObject\_undefine(h, property\_name)

## 📥 Input argument

- h - an QObject handle.
- property\_name - a string : dynamic property name.

## 📤 Output argument

- R - a string: method signature.

## 📄 Description


Undefine a dynamic property of a QObject handle.

## 💡 Example



```matlab
h = errordlg()
set(h, 'myProp', 33)
h
get(h, 'myProp')
QObject_undefine(h, 'myProp')
get(h, 'myProp')
```
