# QObject_used

Returns the current valid QObject handles.

## 📝 Syntax

- r = QObject_used()

## 📤 Output argument

- h - a vector of QObject handle.

## 📄 Description

Returns the current valid QObject handles.

## 💡 Example

```matlab
used = QObject_used()
```
