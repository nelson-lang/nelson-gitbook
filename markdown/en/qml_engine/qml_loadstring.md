# qml\_loadstring

Load a QML string.

## 📝 Syntax

- h = qml\_loadstring(str\_to\_eval)

## 📥 Input argument

- str\_to\_eval - a string.

## 📤 Output argument

- h - a QObject handle.

## 📄 Description


Load a QML string 

It creates a QML component and load .qml file.
