# timeseries.iqr

Interquartile range of timeseries data.

## 📝 Syntax

- y = iqr(ts)

## 📥 Input argument

- ts - Input timeseries object.

## 📤 Output argument

- y - Interquartile range of the timeseries data.

## 📄 Description

<b>iqr</b> Computes the interquartile range of the Data property.

## 💡 Example

```matlab
ts = timeseries([1; 2; 3; 4]);
iqr(ts)

```
