# timeseries.display

Display a timeseries object.

## 📝 Syntax

- display(ts)

## 📥 Input argument

- ts - A timeseries object.

## 📄 Description

<b>display</b> prints a timeseries object with its variable name when available.

## 💡 Example

```matlab
ts = timeseries([1; 2; 3], [10; 11; 12], 'Name', 'speed');
display(ts)

```
