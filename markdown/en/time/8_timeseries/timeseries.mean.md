# timeseries.mean

Mean of timeseries data.

## 📝 Syntax

- y = mean(ts)

## 📥 Input argument

- ts - Input timeseries object.

## 📤 Output argument

- y - Mean of the timeseries data.

## 📄 Description


<b>mean</b> Computes the arithmetic mean of the Data property.

## 💡 Example


```matlab
ts = timeseries([1; 2; 3]);
mean(ts)

```
