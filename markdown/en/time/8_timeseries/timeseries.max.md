# timeseries.max

Maximum of timeseries data.

## 📝 Syntax

- y = max(ts)

## 📥 Input argument

- ts - Input timeseries object.

## 📤 Output argument

- y - Maximum of the timeseries data.

## 📄 Description

<b>max</b> Computes the maximum over the Data property.

## 💡 Example

```matlab
ts = timeseries([1; 3; 2]);
max(ts)

```
