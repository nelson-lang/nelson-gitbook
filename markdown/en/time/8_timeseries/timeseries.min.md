# timeseries.min

Minimum of timeseries data.

## 📝 Syntax

- y = min(ts)

## 📥 Input argument

- ts - Input timeseries object.

## 📤 Output argument

- y - Minimum of the timeseries data.

## 📄 Description


<b>min</b> Computes the minimum over the Data property.

## 💡 Example


```matlab
ts = timeseries([2; 1; 3]);
min(ts)

```
