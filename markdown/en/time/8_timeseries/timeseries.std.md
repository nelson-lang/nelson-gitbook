# timeseries.std

Standard deviation of timeseries data.

## 📝 Syntax

- y = std(ts)

## 📥 Input argument

- ts - Input timeseries object.

## 📤 Output argument

- y - Standard deviation of the timeseries data.

## 📄 Description


<b>std</b> Computes the standard deviation of the Data property.

## 💡 Example


```matlab
ts = timeseries([1; 2; 3]);
std(ts)

```
