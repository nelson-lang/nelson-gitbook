# timeseries.mode

Mode of timeseries data.

## 📝 Syntax

- y = mode(ts)

## 📥 Input argument

- ts - Input timeseries object.

## 📤 Output argument

- y - Mode of the timeseries data.

## 📄 Description


<b>mode</b> Computes the mode of the Data property.

## 💡 Example


```matlab
ts = timeseries([1; 2; 2; 3]);
mode(ts)

```
