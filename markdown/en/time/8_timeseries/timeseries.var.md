# timeseries.var

Variance of timeseries data.

## 📝 Syntax

- y = var(ts)

## 📥 Input argument

- ts - Input timeseries object.

## 📤 Output argument

- y - Variance of the timeseries data.

## 📄 Description


<b>var</b> Computes the variance of the Data property.

## 💡 Example


```matlab
ts = timeseries([1; 2; 3]);
var(ts)

```
