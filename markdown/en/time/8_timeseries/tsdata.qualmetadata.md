# tsdata.qualmetadata

Time series object function.

## 📝 Syntax

- qualmetadata(...)

## 📄 Description


<b>qualmetadata</b> operates on timeseries, tscollection, or tsdata metadata objects.

## 💡 Example


```matlab
info = tsdata.qualmetadata('Code', [1], 'Description', {'ok'});
info.Description

```
