# timeseries.sum

Sum of timeseries data.

## 📝 Syntax

- y = sum(ts)

## 📥 Input argument

- ts - Input timeseries object.

## 📤 Output argument

- y - Sum of the timeseries data.

## 📄 Description


<b>sum</b> Computes the sum of the Data property.

## 💡 Example


```matlab
ts = timeseries([1; 2; 3]);
sum(ts)

```
