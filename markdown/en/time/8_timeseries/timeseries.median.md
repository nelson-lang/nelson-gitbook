# timeseries.median

Median of timeseries data.

## 📝 Syntax

- y = median(ts)

## 📥 Input argument

- ts - Input timeseries object.

## 📤 Output argument

- y - Median of the timeseries data.

## 📄 Description


<b>median</b> Computes the median of the Data property.

## 💡 Example


```matlab
ts = timeseries([1; 5; 3]);
median(ts)

```
