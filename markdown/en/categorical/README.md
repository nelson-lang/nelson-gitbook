# Categorical arrays


    
The Categorical module provides arrays whose elements belong to a fixed set of text categories.

  

## Functions

- [addcats](addcats.md) - Add categories to a categorical array.
- [categorical](categorical.md) - Create a categorical array.
- [categories](categories.md) - List categories of a categorical array.
- [combinations](combinations.md) - Generate all combinations of categorical values.
- [countcats](countcats.md) - Count categorical elements by category.
- [histcounts](histcounts.md) - Count categorical values for histogram-style summaries.
- [iscategorical](iscategorical.md) - Determine whether an array is categorical.
- [iscategory](iscategory.md) - Determine whether names are categories.
- [isordinal](isordinal.md) - Determine whether a categorical array is ordinal.
- [isprotected](isprotected.md) - Determine whether a categorical array is protected.
- [isundefined](isundefined.md) - Find undefined categorical elements.
- [mergecats](mergecats.md) - Merge categories in a categorical array.
- [removecats](removecats.md) - Remove categories from a categorical array.
- [renamecats](renamecats.md) - Rename categories in a categorical array.
- [reordercats](reordercats.md) - Reorder categories in a categorical array.
- [setcats](setcats.md) - Set the category list of a categorical array.
