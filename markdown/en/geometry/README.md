# Geometry


    
The Geometry module provides tools for performing geometric transformations and computations in Nelson.

    
It supports rotation operations in three-dimensional space, convex hulls, Delaunay triangulations, Voronoi diagrams, spatial searches, and scattered data interpolation.

    
This module is useful for applications in computer graphics, robotics, computational geometry, interpolation, and spatial analysis.

  

## Functions

- [alphaShape](alphaShape.md) - Alpha shape object
- [boundary](boundary.md) - Boundary facets of a set of points
- [convhull](convhull.md) - Convex hull of 2-D or 3-D points
- [convhulln](convhulln.md) - Convex hull in N dimensions
- [delaunay](delaunay.md) - Delaunay triangulation of 2-D or 3-D points
- [delaunayTriangulation](delaunayTriangulation.md) - Delaunay triangulation object
- [delaunayn](delaunayn.md) - Delaunay triangulation in N dimensions
- [dsearchn](dsearchn.md) - Nearest point search
- [griddata](griddata.md) - Interpolate scattered data
- [rotx](rotx.md) - 3x3 transformation matrix for rotations around x-axis
- [roty](roty.md) - 3x3 transformation matrix for rotations around y-axis
- [rotz](rotz.md) - 3x3 transformation matrix for rotations around z-axis
- [scatteredInterpolant](scatteredInterpolant.md) - Scattered data interpolant object
- [stlread](stlread.md) - Create triangulation from STL file
- [stlwrite](stlwrite.md) - Create STL file from triangulation
- [triangulation](triangulation.md) - Triangulation object
- [tsearchn](tsearchn.md) - Point location in a triangulation
- [voronoi](voronoi.md) - Voronoi diagram of planar points
- [voronoin](voronoin.md) - Voronoi diagram in N dimensions
