# libpointer\_used

Returns the current valid libpointer handles.

## 📝 Syntax

- r = libpointer\_used()

## 📤 Output argument

- h - a vector of libpointer handle.

## 📄 Description


Returns the current valid libpointer handles.

## 💡 Example



```matlab
used = libpointer_used()
```
