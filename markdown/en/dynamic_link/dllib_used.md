# dllib_used

Returns the current valid dllib handles.

## 📝 Syntax

- r = dllib_used()

## 📤 Output argument

- h - a vector of dllib handle.

## 📄 Description

Returns the current valid dllib handles.

## 💡 Example

```matlab
used = dllib_used()
```
