# libpointer_delete

Removes libpointer object.

## 📝 Syntax

- libpointer_delete(h)
- delete(h)

## 📥 Input argument

- h - a handle: an libpointer object.

## 📄 Description

<b>delete(h)</b> releases libpointer object.

Do not forget to clear h afterward.

## 💡 Example

```matlab
used = libpointer_used()
```
