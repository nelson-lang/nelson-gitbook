# dlsym\_delete

Removes dlsym object.

## 📝 Syntax

- dlsym\_delete(h)
- delete(h)

## 📥 Input argument

- h - a handle: an dlsym object.

## 📄 Description


<b>delete(h)</b> releases dlsym object. 

Do not forget to clear h afterward.

## 💡 Example



```matlab
used = dlsym_used()
```
