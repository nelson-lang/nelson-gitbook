# toolboxdir

Returns path of a module.

## 📝 Syntax

- p = toolboxdir(module\_short\_name)

## 📥 Input argument

- module\_short\_name - a string: short module's name.

## 📤 Output argument

- p - a string: path of the module.

## 📄 Description


<b>toolboxdir</b> is an helper's function to return module root path.

## 💡 Example



```matlab
toolboxdir('core')
```
