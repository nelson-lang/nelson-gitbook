# nmm\_build\_loader

helper's function to build main loader.m of an external module

## 📝 Syntax

- nmm\_build\_loader(module\_short\_name, module\_root\_path)

## 📥 Input argument

- module\_short\_name - a string: short module's name.
- module\_root\_path - a string: path of the module named 'module\_short\_name'.

## 📄 Description


<b>nmm\_build\_loader</b> generates main loader.m of an external module.

## 💡 Example

See module skeleton for example

```matlab
% see builder.m
```
