# doc

Displays documentation.

## 📝 Syntax

- doc
- doc function\_name
- doc('function\_name')

## 📥 Input argument

- function\_name - a string: function name

## 📄 Description


<b>doc</b> launches help browser. 

<b>doc('function\_name')</b> displays the help about function designed by 'function\_name'.

## 💡 Examples



```matlab
doc()
```


```matlab
doc sin
```


```matlab
doc is
```
