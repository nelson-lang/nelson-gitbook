# audioplayer\_used

Returns the current valid audioplayer handles.

## 📝 Syntax

- r = audioplayer\_used()

## 📤 Output argument

- h - a vector of audioplayer handle.

## 📄 Description


Returns the current valid audioplayer handles.

## 💡 Example



```matlab
used = audioplayer_used()
```
