# audiorecorder_used

Returns the current valid audiorecorder handles.

## 📝 Syntax

- r = audiorecorder_used()

## 📤 Output argument

- h - a vector of audiorecorder handle.

## 📄 Description

Returns the current valid audiorecorder handles.

## 💡 Example

```matlab
used = audiorecorder_used()
```
