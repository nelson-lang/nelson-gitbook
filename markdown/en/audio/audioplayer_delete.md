# audioplayer_delete

Removes audioplayer object.

## 📝 Syntax

- audioplayer_delete(h)
- delete(h)

## 📥 Input argument

- h - a handle: an audioplayer object.

## 📄 Description

<b>delete(h)</b> releases audioplayer object.

Do not forget to clear h afterward.

## 💡 Example

```matlab
used = audioplayer_used()
```
