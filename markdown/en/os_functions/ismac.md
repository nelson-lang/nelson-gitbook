# ismac

Checks if version is for MacOS platform.

## 📝 Syntax

- s = ismac()

## 📤 Output argument

- s - a logical: true if it is a MacOS platform.

## 📄 Description


<b>ismac</b> checks if it is a MacOs platform.

## 💡 Example



```matlab
if ismac
  disp('Your platform is MacOs')
else
  disp('Your platform is not MacOs')
end
```
