# isenum

Determine whether the input is an enumeration.

## 📝 Syntax

- tf = isenum(X)

## 📥 Input argument

- X - input value.

## 📤 Output argument

- tf - logical scalar, true if X is an enumeration.

## 📄 Description


<b>isenum</b> returns true if X is an instance of an enumeration class, and false otherwise.

## 💡 Example



```matlab
tf = isenum(3)
```
