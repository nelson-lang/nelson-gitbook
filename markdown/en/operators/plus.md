# plus

Addition, + operator

## 📝 Syntax

- C = plus(A, B)
- C = A + B

## 📥 Input argument

- A - a variable
- B - a variable

## 📤 Output argument

- C - result of A + B

## 📄 Description

<b>C = plus(A, B)</b> performs addition A + B variables.

## 💡 Examples

```matlab
plus(3, 4)
3 + 4
```

```matlab
[1, 2] + 1
plus([1, 2], 1)
```

```matlab
ones(0, 0) + 1
```

Add a character code and a numeric value.

```matlab
char(65) + 1
char(65) + int8([1 2])
```
