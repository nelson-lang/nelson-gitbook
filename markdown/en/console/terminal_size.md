# terminal\_size

Query the size of the terminal window.

## 📝 Syntax

- [r, c] = terminal\_size()

## 📤 Output argument

- [r, c] - a vector: rows and columns

## 📄 Description


<b>terminal\_size()</b> returns a vector with size of the terminal window in characters (rows and columns).

## 💡 Example



```matlab
terminal_size()
```
