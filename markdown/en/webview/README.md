# Web view


    
The WebView module opens local HTML, inline HTML text, web addresses and the examples gallery from Nelson.

  

## Functions

- [demo](demo.md) - Browse examples from loaded Nelson modules and external toolboxes.
- [nelson.htmlviewer.htmlviewer](nelson_htmlviewer_htmlviewer.md) - Handle to a Nelson HTML viewer window.
- [web](web.md) - Open a web page, local file, or HTML text.
