# nelson.unittest.makeref

Create a reference file for a test.

## 📝 Syntax

- status = nelson.unittest.makeref(filename)

## 📥 Input argument

- filename - test file used to create the reference output.

## 📤 Output argument

- status - true when the reference file was created successfully.

## 📄 Description


<b>nelson.unittest.makeref</b> creates the reference file used by reference-based tests. <b>test\_makeref</b> is the compatibility alias.
