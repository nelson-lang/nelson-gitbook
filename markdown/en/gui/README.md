# Gui module

The GUI module provides functions to create and interact with graphical user interface components, dialogs, and application windows.

## Functions

- [commandhistory](commandhistory.md) - Command History
- [dialog](dialog.md) - Creates a dialog figure window.
- [errordlg](errordlg.md) - Creates an error dialog box.
- [filebrowser](filebrowser.md) - Current Folder Browser
- [helpdlg](helpdlg.md) - Creates a help dialog box.
- [inputdlg](inputdlg.md) - Opens an input dialog box.
- [inserthtml](inserthtml.md) - Insert html in GUI console.
- [listdlg](listdlg.md) - Opens a list selection dialog box.
- [lookandfeel](lookandfeel.md) - default current application look and feel.
- [msgbox](msgbox.md) - Creates a message dialog box.
- [openvar](openvar.md) - Open variable in the Variable Editor
- [qt_verbose](qt_verbose.md) - show/hide Qt debug message.
- [questdlg](questdlg.md) - Creates a question dialog box.
- [terminal](terminal.md) - Shell terminal in GUI mode
- [uialert](uialert.md) - Displays an alert dialog for a UI figure.
- [uiconfirm](uiconfirm.md) - Displays a confirmation dialog for a UI figure.
- [uifigure](uifigure.md) - Create a figure for app-style user interfaces.
- [uigetdir](uigetdir.md) - Opens a directory selection dialog box.
- [uigetfile](uigetfile.md) - Opens a file selection dialog box.
- [uiopen](uiopen.md) - Loads a file selected from a dialog box.
- [uiprogressdlg](uiprogressdlg.md) - Creates a UI progress dialog.
- [uiputfile](uiputfile.md) - Opens a file save dialog box.
- [uisave](uisave.md) - Saves workspace variables to a file selected from a dialog box.
- [uisetcolor](uisetcolor.md) - Opens a color selection dialog box.
- [uisetfont](uisetfont.md) - Opens a font selection dialog box.
- [waitbar](waitbar.md) - Creates or updates a wait bar figure.
- [warndlg](warndlg.md) - Creates a warning dialog box.
- [workspace](workspace.md) - Workspace Browser
