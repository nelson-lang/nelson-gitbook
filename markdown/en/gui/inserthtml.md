# inserthtml

Insert html in GUI console.

## 📝 Syntax

- inserthtml(html\_txt)

## 📥 Input argument

- html\_txt - a string: html text

## 📄 Description


<b>inserthtml</b> inserts html code in GUI console.

## 💡 Example



```matlab
inserthtml(markdown(fileread([nelsonroot(),'/CHANGELOG.md'])))
```
