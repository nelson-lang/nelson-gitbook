# pow2db

Convert power to decibel.

## 📝 Syntax

- db = pow2db(pow)

## 📥 Input argument

- pow - input array: scalar, vector or matrix.

## 📤 Output argument

- db - corresponding values in decibels

## 📄 Description


<b>db = pow2db(pow)</b> returns corresponding values in decibels.

## 💡 Example



```matlab
DB = pow2db([1, 0.01])
```
