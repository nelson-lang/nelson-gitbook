# rectwin

Rectangular window.

## 📝 Syntax

- W = rectwin(M)

## 📥 Input argument

- M - window length.

## 📤 Output argument

- W - column vector containing the window.

## 📄 Description

<b>rectwin</b> returns an M-point rectangular window.

## 💡 Example

```matlab

w = rectwin(4);

```
