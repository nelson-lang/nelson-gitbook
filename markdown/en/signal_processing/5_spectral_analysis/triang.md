# triang

Triangular window.

## 📝 Syntax

- W = triang(M)

## 📥 Input argument

- M - window length.

## 📤 Output argument

- W - column vector containing the window.

## 📄 Description


<b>triang</b> returns an M-point triangular window.

## 💡 Example



```matlab

w = triang(6);

```
