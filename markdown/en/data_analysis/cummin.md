# cummin

Cumulative minimum of array elements.

## 📝 Syntax

- R = cummin(A)
- R = cummin(A, d)

## 📥 Input argument

- A - input array.
- d - dimension to operate along: positive integer scalar.

## 📤 Output argument

- R - Cumulative minimum of array elements.

## 📄 Description


<b>cummin</b> returns cumulative minimum values along the selected dimension.

## 💡 Example



```matlab
A = [3 1 4 2];
R = cummin(A)
```
