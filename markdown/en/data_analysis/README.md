# Data analysis

The Data Analysis module provides tools for performing numerical and array-based analyses in Nelson.

It supports cumulative operations, sorting, aggregation, convolution, and identification of unique or missing values.

This module supports processing, summarization, and exploration of datasets for computational and analytical tasks.

- [allbetween](allbetween.md) - Determine whether all array elements are between lower and upper bounds.
- [bounds](bounds.md) - Smallest and largest array elements.
- [conv](conv.md) - Convolution and polynomial multiplication.
- [conv2](conv2.md) - 2-D convolution.
- [cummax](cummax.md) - Cumulative maximum of array elements.
- [cummin](cummin.md) - Cumulative minimum of array elements.
- [cumprod](cumprod.md) - Cumulative product of array elements.
- [cumsum](cumsum.md) - Cumulative sum of array elements.

- [fillmissing](fillmissing.md) - Fill missing values.
- [groupcounts](groupcounts.md) - Count groups.
- [groupsummary](groupsummary.md) - Compute grouped table summaries.
- [intersect](intersect.md) - Set intersection of two arrays.

- [islocalmax](islocalmax.md) - Detect local maxima in data.
