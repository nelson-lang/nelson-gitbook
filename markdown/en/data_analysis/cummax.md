# cummax

Cumulative maximum of array elements.

## 📝 Syntax

- R = cummax(A)
- R = cummax(A, d)

## 📥 Input argument

- A - input array.
- d - dimension to operate along: positive integer scalar.

## 📤 Output argument

- R - Cumulative maximum of array elements.

## 📄 Description

<b>cummax</b> returns cumulative maximum values along the selected dimension.

## 💡 Example

```matlab
A = [3 1 4 2];
R = cummax(A)
```
