# beta

Beta function.

## 📝 Syntax

- B = beta(Z, W)

## 📥 Input argument

- Z - real scalar, vector, or matrix.
- W - real scalar, vector, or matrix.

## 📤 Output argument

- B - value of the beta function.

## 📄 Description


<b>beta</b> computes the beta function B(Z,W) = gamma(Z).\*gamma(W)./gamma(Z+W).

## 💡 Example



```matlab
B = beta(2, 3)
```
