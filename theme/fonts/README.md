# Fonts of the printed manuals

Every font used by the PDF manuals is vendored here so that the output is the
same on Windows, Linux and macOS. The builder scans this directory
(`FONTS_DIR` in `src/typst_engine.rs`); `nelson-style` in `nelson_help.typ`
(generated by Nelson from `modules/help_tools/resources/nelson_help.typ`)
lists them first.

| Family | Files | Role | Source | Licence |
|---|---|---|---|---|
| Noto Sans | `NotoSans-{Regular,Bold,Italic,BoldItalic,SemiBold}.ttf` | body text | https://github.com/notofonts/notofonts.github.io (`fonts/NotoSans/hinted/ttf`) | `OFL-NotoSans.txt` |
| Noto Sans Math | `NotoSansMath-Regular.ttf` | mathematical symbols in running text | https://github.com/notofonts/notofonts.github.io (`fonts/NotoSansMath/hinted/ttf`) | `OFL-NotoSansMath.txt` |
| Noto Sans JP | `NotoSansJP-Regular.otf` | Japanese examples of the character encoding pages | https://github.com/notofonts/noto-cjk (`Sans/SubsetOTF/JP`) | `OFL-NotoSansJP.txt` |
| Noto Emoji | `NotoEmoji[wght].ttf` | the few emoji of the changelogs (monochrome) | https://github.com/google/fonts (`ofl/notoemoji`) | `OFL-NotoEmoji.txt` |
| JetBrains Mono | `JetBrainsMono-{Regular,Bold,Italic}.ttf` | code | https://github.com/JetBrains/JetBrainsMono (`fonts/ttf`) | `OFL-JetBrainsMono.txt` |

Mathematical formulas (`latex()` / mitex) use the New Computer Modern Math
font embedded in the builder, and DejaVu Sans Mono, also embedded, completes
JetBrains Mono in code blocks.

Text inside SVG figures (block icons exported by NFlow) is resolved by the
SVG renderer from the fonts the figure names; those labels may still pick a
system font.
