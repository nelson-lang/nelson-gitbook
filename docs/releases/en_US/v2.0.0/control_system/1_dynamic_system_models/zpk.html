zpk
Constructs a zero-pole-gain model.
📝Syntax
sys = zpk()
sys = zpk('s')
sys = zpk(z, p, k)
sys = zpk(z, p, k, Ts)
sys = zpk(sysIn)
📥Input Arguments
Parameter Description
z zeros: a vector (or cell array of vectors).
p poles: a vector (or cell array of vectors).
k scalar gain.
Ts Sampling time Ts, default: in seconds
sysIn LTI model.
📤Output Arguments
Parameter Description
sys Output zero-pole-gain system model.
📄Description

sys = zpk(z, p, k) creates a continuous-time zero-pole-gain model.

The model represents the transfer function k * (s - z(1))...(s - z(end)) / ((s - p(1))...(s - p(end))) where z are the zeros, p the poles and k the scalar gain.

When you include the Ts parameter, it allows you to create a discrete-time zero-pole-gain model.

sys = zpk(sysIn) converts the LTI model sysIn (tf or ss) into a zero-pole-gain model.

Complex zeros and poles of a real system must come in conjugate pairs. The model is displayed in factored form.

💡Examples
z = -1;
p = [-2 -3];
k = 5;
sys = zpk(z, p, k)
sys = zpk(-1, [-2 -3], 5);
G = tf(sys)
