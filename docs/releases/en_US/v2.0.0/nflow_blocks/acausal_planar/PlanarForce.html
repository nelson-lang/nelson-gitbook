PlanarForce
External world force (fx, fy) applied at the frame-a point (adds a torque when offset from the COM).
📝Syntax
Block type: PlanarForce
📥Input Arguments
Parameter Description
physical pins 1 undirected physical pin(s); 0 signal input(s).
📤Output Arguments
Parameter Description
signal ports 0 signal output(s) (sensor readings).
📄Description

External world force (fx, fy) applied at the frame-a point (adds a torque when offset from the COM).

Module nflow_blocks
Library Planar (acausal)
Type PlanarForce
Label PlanarForce
Solver Lowered to planarMechanicalIsland. Reference solver dae (differential-algebraic); the fixed-step loop and the native explicit solvers (ode1/ode4/ode45) are also supported (a jointed multibody island requires dae).
