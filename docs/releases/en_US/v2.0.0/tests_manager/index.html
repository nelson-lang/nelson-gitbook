Tests framework for Nelson

The Test Manager module in Nelson provides tools for automated testing of code, enabling users to validate functionality, ensure correctness, and manage test cases efficiently.

This module supports creating reference outputs, running test suites, and conditionally skipping tests.

  • bench_run
    Run benchmarks
  • nelson.unittest
    Modern test runner namespace
  • nelson.unittest.assume
    Skip a test when a runtime assumption is not satisfied.
  • nelson.unittest.discover
    Discover test files and return a structured suite.
  • nelson.unittest.makeref
    Create a reference file for a test.
  • nelson.unittest.plan
    Create an execution plan for a test suite.
  • nelson.unittest.report
    Write test and benchmark runner reports.
  • nelson.unittest.run
    Run tests through the modern test runner.
  • nelson.unittest.select
    Filter a discovered test suite.
  • nelson.unittest.skip
    Skip the current test.
  • nelson.unittest.tuneReuse
    Calibrate explicit child-process reuse for tests and benches.
  • nelson.unittest.tuneWeights
    Calibrate scheduling weights from measured test durations.
  • test_makeref
    Creates a '.ref' file for a test
  • test_run
    Runs tests
  • skip_testsuite
    Skip test suite on condition
