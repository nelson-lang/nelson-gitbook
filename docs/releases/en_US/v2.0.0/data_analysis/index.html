Data analysis

The Data Analysis module provides tools for performing numerical and array-based analyses in Nelson.

It supports cumulative operations, sorting, aggregation, convolution, and identification of unique or missing values.

This module supports processing, summarization, and exploration of datasets for computational and analytical tasks.

  • accumarray
    Construct array by accumulation.
  • allbetween
    Determine whether all array elements are between lower and upper bounds.
  • bounds
    Smallest and largest array elements.
  • conv
    Convolution and polynomial multiplication.
  • conv2
    2-D convolution.
  • cummax
    Cumulative maximum of array elements.
  • cummin
    Cumulative minimum of array elements.
  • cumprod
    Cumulative product of array elements.
  • cumsum
    Cumulative sum of array elements.
  • detrend
    Remove polynomial trend.
  • discretize
    Group numeric data into bins.
  • fillmissing
    Fill missing values.
  • groupcounts
    Count groups.
  • groupsummary
    Compute grouped table summaries.
  • intersect
    Set intersection of two arrays.
  • isbetween
    Determine array elements between lower and upper bounds.
  • islocalmax
    Detect local maxima in data.
  • islocalmin
    Detect local minima in data.
  • ismembertol
    Members of a set within a tolerance.
  • ismissing
    Check for missing values.
  • issorted
    Determine if array is sorted.
  • max
    Maximum elements of an array.
  • min
    Minimum elements of an array.
  • movmad
    Moving median absolute deviation.
  • movmax
    Moving maximum.
  • movmean
    Moving mean.
  • movmedian
    Moving median.
  • movmin
    Moving minimum.
  • movprod
    Moving product.
  • movstd
    Moving standard deviation.
  • movsum
    Moving sum.
  • movvar
    Moving variance.
  • normalize
    Normalize data.
  • prod
    Product of array elements.
  • rmmissing
    Remove missing data.
  • setdiff
    Set difference of two arrays.
  • setxor
    Set exclusive OR of two arrays.
  • smoothdata
    Smooth noisy data.
  • sort
    Sort array elements by quick sort algorithm.
  • standardizeMissing
    Convert indicator values to standard missing values.
  • subspace
    Measure of distance (angle) between two subspaces spanned by columns of matrices.
  • sum
    Sum of array elements.
  • summary
    Summarize table variables or categorical values.
  • union
    Set union of two arrays.
  • unique
    Unique values.
  • uniquetol
    Unique values within a tolerance.
