Handle

The Handle module provides tools for creating and manipulating handle objects in Nelson.

Handle objects are lightweight references to larger data structures, enabling efficient memory management and data sharing between different parts of a program.

This module includes functions for creating, copying, and destroying handle objects, as well as for managing their lifetimes and ensuring proper cleanup.

It also includes classdef reflection, event, listener, dynamic property, weak reference, and typed invalid handle helpers.

  • addlistener
    Adds a listener callback to a classdef event.
  • cancel
    Cancel a cancellable object.
  • delete
    Delete handle objects or files.
  • dynamicprops
    Base class for handle objects with instance dynamic properties.
  • enumeration
    Returns enumeration member names for a classdef enumeration class.
  • events
    Returns event names for a classdef object or class.
  • get
    Retrieve a property value from an handle object.
  • handle
    Base class for objects with reference semantics.
  • insert
    Insert entries into an object that supports keyed insertion.
  • invoke
    Invoke method on an handle object.
  • isKey
    Determine whether an object contains a key.
  • ismethod
    Return true if a public method belongs to an object or class.
  • isprop
    Return true if a property belongs to an object or class.
  • isvalid
    Return true for valid handles.
  • listener
    Creates a classdef event listener.
  • lookup
    Look up values in an object.
  • metaclass
    Returns classdef metadata.
  • methods
    Returns public method names for an object or class.
  • nelson.lang.HandlePlaceholder
    Placeholder handle class used for missing handle targets.
  • nelson.lang.WeakReference
    Weak reference to a handle object.
  • nelson.lang.invalidHandle
    Create an invalid handle with a specified handle class.
  • nelson.mixin.Copyable
    Add a copy method to a handle class.
  • nelson.mixin.CustomCompactDisplayProvider
    Provide a compact display of an object inside containers.
  • nelson.mixin.CustomDisplay
    Customize how an object is displayed.
  • nelson.mixin.Heterogeneous
    Allow arrays that mix related classes.
  • nelson.mixin.Scalar
    Restrict a class to scalar instances.
  • nelson.mixin.SetGet
    Add set and get property access to a handle class.
  • nelson.mixin.SetGetExactNames
    Set and get property access with case-sensitive names.
  • notify
    Notifies listeners of a classdef event.
  • properties
    Returns public property names for an object or class.
  • remove
    Remove entries from an object.
  • set
    Set a property value of an handle object.
  • superclasses
    Names of the superclasses of a class.
