Geometry

The Geometry module provides tools for performing geometric transformations and computations in Nelson.

It supports rotation operations in three-dimensional space, convex hulls, Delaunay triangulations, Voronoi diagrams, spatial searches, and scattered data interpolation.

This module is useful for applications in computer graphics, robotics, computational geometry, interpolation, and spatial analysis.

  • alphaShape
    Alpha shape object
  • boundary
    Boundary facets of a set of points
  • convhull
    Convex hull of 2-D or 3-D points
  • convhulln
    Convex hull in N dimensions
  • delaunay
    Delaunay triangulation of 2-D or 3-D points
  • delaunayTriangulation
    Delaunay triangulation object
  • delaunayn
    Delaunay triangulation in N dimensions
  • dsearchn
    Nearest point search
  • griddata
    Interpolate scattered data
  • rotx
    3x3 transformation matrix for rotations around x-axis
  • roty
    3x3 transformation matrix for rotations around y-axis
  • rotz
    3x3 transformation matrix for rotations around z-axis
  • scatteredInterpolant
    Scattered data interpolant object
  • stlread
    Create triangulation from STL file
  • stlwrite
    Create STL file from triangulation
  • triangulation
    Triangulation object
  • tsearchn
    Point location in a triangulation
  • voronoi
    Voronoi diagram of planar points
  • voronoin
    Voronoi diagram in N dimensions
