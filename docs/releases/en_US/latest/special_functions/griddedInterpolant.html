griddedInterpolant
Gridded data interpolant object
📝Syntax
F = griddedInterpolant(x, v)
F = griddedInterpolant(x, v, method)
F = griddedInterpolant(x, v, method, extrapolationMethod)
F = griddedInterpolant(gridVecs, V)
F = griddedInterpolant(X1, X2, ..., Xn, V)
F = griddedInterpolant(V)
Vq = F(xq)
Vq = F(xq1, xq2, ..., xqn)
Vq = F(queryGridVecs)
📥Input Arguments
Parameter Description
x a vector of sample points (1-D grid), strictly increasing.
v sample values at the sample points.
gridVecs a cell array {x1, x2, ..., xn} of grid vectors, one per dimension of V.
V an array of sample values defined over the grid.
method a character vector: 'linear' (default), 'nearest', 'previous', 'next', 'pchip', 'cubic', 'spline', or 'makima'.
extrapolationMethod a character vector selecting the extrapolation rule: 'linear', 'nearest', 'previous', 'next', 'pchip', 'cubic', 'spline', 'makima', or 'none'. The default matches method.
📤Output Arguments
Parameter Description
F a griddedInterpolant object.
Vq interpolated values at the query points.
📄Description

griddedInterpolant stores gridded sample points and values for repeated interpolation queries.

The object exposes four properties that can be read and set: GridVectors (a cell array of grid vectors), Values, Method, and ExtrapolationMethod.

Evaluate the interpolant by calling the object like a function, either with one query array per dimension, or with a single cell array of query grid vectors.

The 'cubic' method uses cubic convolution and requires a grid with uniform spacing; on a non-uniform grid it switches to 'spline'. Cubic convolution does not support extrapolation, so query points outside the grid return NaN when ExtrapolationMethod is 'cubic'.

💡Examples
1-D interpolation.
F = griddedInterpolant([1 2 3], [10 20 30]);
Vq = F(2.5)
N-D grid given as a cell of grid vectors.
F = griddedInterpolant({1:3, 1:3}, magic(3));
Vq = F(2, 2)
Spline interpolation and property readback.
F = griddedInterpolant([1 2 3], [10 20 30], 'spline');
Vq = F(2.5);
