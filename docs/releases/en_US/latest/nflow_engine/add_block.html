add_block
Add a block to an nflow model from a library source.
📝Syntax
h = add_block(source, destination)
h = add_block(source, destination, name, value, ...)
h = add_block(source, destination, 'MakeNameUnique', 'on')
📥Input Arguments
Parameter Description
args see the syntaxes above.
📤Output Arguments
Parameter Description
varargout see the syntaxes above.
📄Description

add_block adds a block to an nflow model from a library source.

💡Examples
new_system('demo');
add_block('nflow/source/sine', 'demo/Sine');
add_block('nflow/math/gain', 'demo/Gain', 'gain', 2);
add_line('demo', 'Sine/1', 'Gain/1');
bdclose('demo');
