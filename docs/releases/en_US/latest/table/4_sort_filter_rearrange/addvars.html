addvars
Add variables to a table or timetable.
📝Syntax
TB = addvars(TA, X)
TB = addvars(TA, X1, ... , XN, 'NewVariableNames', names)
TB = addvars(TA, X, 'Before', varName)
TB = addvars(TA, X, 'After', varName)
📥Input Arguments
Parameter Description
TA Input table or timetable.
X, X1, ... , XN Variable data to add. Each variable must have the same number of rows as TA.
names Names for the new variables.
varName Reference variable used with Before or After.
📤Output Arguments
Parameter Description
TB Table or timetable with added variables.
📄Description

addvars adds one or more variables to a table and updates T.Properties.VariableNames.

New variables are appended by default. Use Before or After to choose the insertion position.

Without NewVariableNames, a variable passed by name keeps that name and any other input is named Var followed by its column number; a name already used by the table or by another new variable is suffixed with _1, _2, ...

For a timetable, the row times and the timetable properties are kept.

💡Examples
Add a variable at the end of a table
T = table([1; 2], 'VariableNames', {'A'});
T = addvars(T, [3; 4], 'NewVariableNames', {'B'})
Add a variable before an existing variable
T = table([1; 2], [5; 6], 'VariableNames', {'A', 'C'});
T = addvars(T, [3; 4], 'NewVariableNames', {'B'}, 'Before', 'C')
