SpringDamper
Parallel spring and damper: F = k (s_a - s_b) + d (v_a - v_b).
📝Syntax
Block type: SpringDamper
📥Input Arguments
Parameter Description
physical pins 2 undirected physical pin(s); 0 signal input(s).
📤Output Arguments
Parameter Description
signal ports 0 signal output(s) (sensor readings).
📄Description

Parallel spring and damper: F = k (s_a - s_b) + d (v_a - v_b).

Module nflow_blocks
Library Translational (acausal)
Type SpringDamper
Label SpringDamper
Solver Lowered to mechanicalTranslationalIsland. Reference solver dae (differential-algebraic); the fixed-step loop and the native explicit solvers (ode1/ode4/ode45) are also supported (a jointed multibody island requires dae).
