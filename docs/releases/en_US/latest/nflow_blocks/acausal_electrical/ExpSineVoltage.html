ExpSineVoltage
Exponentially damped sine voltage source.
📝Syntax
Block type: ExpSineVoltage
📥Input Arguments
Parameter Description
physical pins 2 undirected physical pin(s); 0 signal input(s).
📤Output Arguments
Parameter Description
signal ports 0 signal output(s) (sensor readings).
📄Description

Exponentially damped sine voltage source.

Module nflow_blocks
Library Electrical (acausal)
Type ExpSineVoltage
Label ExpSineVoltage
Solver Lowered to physicalIsland. Reference solver dae (differential-algebraic); the fixed-step loop and the native explicit solvers (ode1/ode4/ode45) are also supported (a jointed multibody island requires dae).
