nelson.ode.options.ODE89
Options object for the ode89 solver.
📝Syntax
options = nelson.ode.options.ODE89()
options = nelson.ode.options.ODE89(name, value)
📄Description

nelson.ode.options.ODE89 creates a compatible option class for the 'ode89' solver value used by the ode object workflow.

Option group Names Purpose
Steps InitialStep, MaxStep, MinStep Bound the adaptive step size selection.
Error control NormControl Switch between componentwise and norm based error control.
Output OutputFcn, OutputSelection Select output callbacks and returned components.

The 'ode89' solver value uses a very high order explicit Runge-Kutta (8,9) pair, efficient for very smooth nonstiff problems solved over long intervals with tight tolerances.

Supported properties are InitialStep, MaxStep, MinStep, NormControl, OutputFcn, and OutputSelection. InitialStep, MaxStep, and MinStep are positive scalars bounding the adaptive step size; their default value is empty, which lets the solver choose them automatically. NormControl accepts 'on' or 'off' (default 'off') and enables error control based on the norm of the solution instead of componentwise control. OutputFcn is a function handle called on each output point (default empty). OutputSelection is a vector of indices selecting which solution components are passed to the output function (default empty, all components). The default Refine value for this solver is 8.

💡Examples
Create a nonstiff problem solved with ode89 options.
options = nelson.ode.options.ODE89('NormControl', 'on');
problem = ode('ODEFcn', @(t,y) -y, 'InitialValue', 1, ...
  'SolverOptions', options);
result = solve(problem, 0, 1)
