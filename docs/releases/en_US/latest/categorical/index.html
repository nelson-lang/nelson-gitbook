Categorical arrays

The Categorical module provides arrays whose elements belong to a fixed set of text categories.

  • addcats
    Add categories to a categorical array.
  • categorical
    Create a categorical array.
  • categories
    List categories of a categorical array.
  • combinations
    Generate all combinations of categorical values.
  • countcats
    Count categorical elements by category.
  • histcounts
    Count categorical values for histogram-style summaries.
  • iscategorical
    Determine whether an array is categorical.
  • iscategory
    Determine whether names are categories.
  • isordinal
    Determine whether a categorical array is ordinal.
  • isprotected
    Determine whether a categorical array is protected.
  • isundefined
    Find undefined categorical elements.
  • mergecats
    Merge categories in a categorical array.
  • removecats
    Remove categories from a categorical array.
  • renamecats
    Rename categories in a categorical array.
  • reordercats
    Reorder categories in a categorical array.
  • setcats
    Set the category list of a categorical array.
