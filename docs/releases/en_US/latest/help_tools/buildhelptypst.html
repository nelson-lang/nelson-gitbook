buildhelptypst
Build help of Nelson's modules as Typst sources.
📝Syntax
buildhelptypst(dirdest)
buildhelptypst(dirdest, module_name)
📥Input Arguments
Parameter Description
dirdest a string: a path destination.
module_name a string: module name (module must be loaded).
📄Description

buildhelptypst generates the help as Typst sources, ready to be compiled to PDF.

For each available language, the pages of a module are written to dirdest/<lang>/<module>/ with a main.typ root document (see xmldoctotypst). The root document dirdest/<lang>/main.typ applies the nelson-style page style of nelson_help.typ and includes, in order: the modules, then a table of contents.

With one argument, the whole manual is built: the home page, the getting started guide, the changelogs and the licenses (hand-written markdown pages of the main module, converted to Typst) are added around the modules, as in the markdown manual built by buildhelpmd.

Compile one module with typst compile dirdest/en/core/main.typ, or the whole manual with typst compile dirdest/en/main.typ. The LaTeX fragments of the pages are typeset with the mitex Typst package, downloaded on first use by the typst compiler.

💡Examples
buildhelptypst(tempdir(), 'core');
dir([tempdir(), 'en/core'])
