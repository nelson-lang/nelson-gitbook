extractevents
Extraire une table d'evenements de lignes d'une timetable.
📝Syntaxe
ET = extractevents(TT, rows)
ET = extractevents(TT, labels)
ET = extractevents(..., Name, Value)
[ET, TT2] = extractevents(...)
📥Arguments d'entrée
Paramètre Description
TT Timetable d'entree.
rows Lignes de TT : numeros de lignes, masque logique, instants (datetime ou duration), timerange ou ':'.
labels Vecteur categorical avec un element par ligne de TT : les elements definis sont les libelles des evenements, les lignes a <undefined> ne sont pas des evenements.
Name, Value EventLabels, EventLengths, EventEnds : valeurs (scalaire ou une par evenement) ; EventLabelsVariable, EventLengthsVariable, EventEndsVariable : variable de TT qui les contient ; EventDataVariables : variables de TT copiees dans la table d'evenements ; PreserveEventVariables : true pour garder ces variables dans TT2 (false par defaut).
📤Arguments de sortie
Paramètre Description
ET Table d'evenements : les instants des lignes selectionnees et les variables d'evenements.
TT2 Copie de TT sans les variables copiees dans ET, sauf si PreserveEventVariables vaut true.
📄Description

extractevents cree une table d'evenements a partir de lignes d'une timetable. Seules les variables nommees par les options sont copiees : d'abord la variable des durees ou des fins d'evenements, puis la variable des libelles, puis les variables de donnees, puis les variables creees a partir des valeurs EventLabels, EventLengths et EventEnds.

Une variable d'evenement ne peut pas aussi figurer dans EventDataVariables. PreserveEventVariables necessite au moins une option de variable et la deuxieme sortie.

Pour lire la table d'evenements attachee a une timetable, utiliser TT.Properties.Events.

💡Exemples
TT = timetable(seconds([1; 2; 3; 4]), [10; 20; 30; 40], ["a"; "b"; "c"; "d"], 'VariableNames', {'A', 'L'});
ET = extractevents(TT, [2 4], 'EventLabelsVariable', 'L')
[ET, TT2] = extractevents(TT, timerange(seconds(2), seconds(4)), 'EventDataVariables', 'A')
TT = timetable(seconds([1; 2; 3; 4]), [10; 20; 30; 40], 'VariableNames', {'A'});
ET = extractevents(TT, categorical(["start"; ""; ""; "stop"]))
