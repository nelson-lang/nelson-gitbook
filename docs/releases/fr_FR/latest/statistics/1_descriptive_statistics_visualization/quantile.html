quantile
Quantiles d'un jeu de données.
📝Syntaxe
Q = quantile(A, p)
Q = quantile(A, n)
Q = quantile(A, p, dim)
Q = quantile(A, p, vecdim)
Q = quantile(A, p, 'all')
Q = quantile(..., 'Method', method)
📄Description

quantile retourne les quantiles pour des probabilités dans l'intervalle [0,1]. Si le second argument est un entier supérieur à un, il est interprété comme le nombre de quantiles régulièrement espacés.

Les valeurs NaN sont ignorées. Les méthodes supportées sont midpoint, exact, inclusive, exclusive et approximate.

A peut être un tableau numérique réel, un tableau datetime ou un tableau duration. Pour des données datetime ou duration, les quantiles ont la même classe et le même Format que A, et les valeurs NaT sont ignorées comme les valeurs NaN.

💡Exemples
A = [2 5 6 10 11 13];
Q = quantile(A, [0.25 0.5 0.75])
données datetime et duration
d = hours([1 2 3 4 10]);
Q = quantile(d, [0.25 0.5 0.75])
