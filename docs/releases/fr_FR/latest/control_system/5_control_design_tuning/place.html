place
Placement de pôles par retour d'état avec assignation robuste.
📝Syntaxe
K = place(A, B, p)
[K, prec] = place(A, B, p)
[K, prec, message] = place(A, B, p)
📥Arguments d'entrée
Paramètre Description
A Matrice d'état : matrice Nx-par-Nx.
B Matrice d'entrée vers l'état : matrice Nx-par-Nu.
p Vecteur des pôles désirés en boucle fermée, de longueur Nx.
📤Arguments de sortie
Paramètre Description
K Matrice de gain du retour d'état : matrice Nu-par-Nx.
prec Précision estimée des pôles assignés, exprimée comme un nombre approximatif de décimales exactes.
message Message d'avertissement renvoyé lorsqu'un ou plusieurs pôles n'ont pas pu être placés à la précision demandée (vide sinon).
📄Description

La fonction place calcule la matrice de gain K telle que les pôles en boucle fermée de A - B*K soient les éléments du vecteur p, c'est-à-dire p = eig(A - B*K).

Contrairement à acker, limitée aux systèmes mono-entrée, place prend en charge les systèmes multi-entrées (B à plusieurs colonnes) et choisit les vecteurs propres en boucle fermée de façon à rendre l'assignation aussi peu sensible que possible aux perturbations.

Les pôles complexes désirés doivent être fournis par paires conjuguées. La multiplicité d'un pôle ne peut pas dépasser le rang de B. Pour des A, B et p réels, le gain K obtenu est réel.

L'algorithme est la méthode de mise à jour de rang un décrite dans J. Kautsky, N. K. Nichols et P. Van Dooren, "Robust pole assignment in linear state feedback", International Journal of Control, vol. 41, no. 5, pp. 1129-1155, 1985.

💡Exemples
A = [-0.5 0 0; 0 -2 10; 0 1 -2];
B = [1 0; 0 0; 0 1];
p = [-3; -5; -7];
[K, prec] = place(A, B, p)
eig(A - B * K)
