smoothdata
Lisse des donnees bruitees.
📝Syntaxe
B = smoothdata(A)
B = smoothdata(A, method)
B = smoothdata(A, method, window)
B = smoothdata(A, dim)
B = smoothdata(A, dim, method)
B = smoothdata(A, dim, method, window)
B = smoothdata(__, nanflag)
B = smoothdata(__, Name, Value)
[B, window] = smoothdata(__)
📥Arguments d'entrée
Paramètre Description
A vecteur ou matrice d'entree : numerique ou logique.
method un vecteur de caracteres ou une chaine : methode de lissage. Voir la description pour la liste des methodes supportees.
window un scalaire positif ou un vecteur a deux elements [arriere avant] : longueur de la fenetre glissante.
dim dimension le long de laquelle operer : entier positif scalaire.
nanflag un vecteur de caracteres ou une chaine : 'omitnan' (par defaut) ou 'includenan'.
Name, Value paires nom/valeur : 'SamplePoints', 'SmoothingFactor', 'Degree'.
📤Arguments de sortie
Paramètre Description
B donnees lissees.
window longueur de la fenetre glissante utilisee pour le lissage.
📄Description

smoothdata lisse des donnees bruitees dans un vecteur ou dans les colonnes d'une matrice.

Par defaut, smoothdata opere le long de la premiere dimension non singleton avec la methode 'movmean' et une longueur de fenetre heuristique choisie a partir des donnees.

Les valeurs supportees de method sont :

'movmean' : moyenne glissante sur chaque fenetre (par defaut).

'movmedian' : mediane glissante sur chaque fenetre.

'gaussian' : moyenne ponderee glissante avec des poids gaussiens.

'lowess' : regression locale avec un polynome de degre un.

'loess' : regression locale avec un polynome de degre deux.

'sgolay' : filtre polynomial de Savitzky-Golay (utiliser 'Degree' pour fixer le degre du polynome, 2 par defaut).

Le drapeau 'omitnan' (par defaut) ignore les valeurs NaN dans chaque fenetre, tandis que 'includenan' les propage.

'SmoothingFactor' est un scalaire entre 0 et 1 qui regle la longueur de fenetre choisie automatiquement ; des valeurs plus grandes lissent davantage.

'SamplePoints' est un vecteur de coordonnees d'echantillonnage uniformement espacees ; la fenetre est alors exprimee dans les unites de ces coordonnees.

Les methodes robustes 'rlowess' et 'rloess' ne sont pas encore supportees.

💡Exemples
moyenne glissante
A = [1 2 10 4 5];
B = smoothdata(A, 'movmean', 3)
lissage gaussien
A = [1 2 10 4 5];
B = smoothdata(A, 'gaussian', 3)
fenetre choisie automatiquement
A = [1 2 10 4 5];
[B, window] = smoothdata(A)
