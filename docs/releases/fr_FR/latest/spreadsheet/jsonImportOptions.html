jsonImportOptions
Créer des options pour importer des données JSON.
📝Syntaxe
opts = jsonImportOptions()
opts = jsonImportOptions('NumVariables', numVars)
opts = jsonImportOptions(..., Name, Value)
📥Arguments d'entrée
Paramètre Description
numVars nombre de variables (défaut : 1).
Name, Value noms et valeurs des propriétés de l'objet, et 'ParsingMode' ('lenient' ou 'strict') qui fixe AllowComments, AllowInfAndNaN et AllowTrailingCommas.
📤Arguments de sortie
Paramètre Description
opts Objet nelson.io.json.JSONImportOptions.
📄Description

jsonImportOptions crée un objet d'options d'importation pour les fichiers JSON, à utiliser avec readtable et readtimetable. detectImportOptions renvoie le même objet, rempli à partir d'un fichier JSON.

Propriétés :

  • VariableNames : noms des variables (défaut : Var1, Var2, ...).
  • VariableNamingRule : 'preserve' (défaut) ou 'modify'.
  • VariableTypes : types des variables : 'double', 'single', types entiers, 'logical', 'string', 'char', 'categorical', 'datetime', 'duration' ou 'cell' (défaut : 'char').
  • SelectedVariableNames : sous-ensemble des variables à importer.
  • VariableSelectors : pointeurs JSON RFC 6901 des variables, relatifs à un objet ligne. "Keys" lit les clés des objets. Si vide, toutes les valeurs feuilles sont lues.
  • RowNamesSelector : pointeur JSON des noms de lignes.
  • TableSelector : pointeur JSON de la table ("", le défaut, désigne le fichier entier).
  • VariableDescriptionsSelector, VariableUnitsSelector : pointeurs JSON des descriptions et des unités des variables.
  • ImportErrorRule, MissingRule : 'fill' (défaut), 'error', 'omitrow' ou 'omitvar'.
  • RepeatedNodeRule : 'addcol' (défaut), 'ignore' ou 'error'.
  • AllowComments, AllowInfAndNaN, AllowTrailingCommas : acceptent les commentaires, les valeurs Inf et NaN, les virgules finales (défaut : true).

L'objet utilise la classe Nelson nelson.io.json.JSONImportOptions.

💡Exemples
Sélectionner une valeur imbriquée de chaque ligne :
f = [tempdir, 'students.json']; fid = fopen(f, 'w'); fprintf(fid, '%s', '[{"Name": {"FirstName": "Priya"}}, {"Name": {"FirstName": "Conor"}}]'); fclose(fid); opts = jsonImportOptions('VariableSelectors', "/Name/FirstName", 'TableSelector', "") T = readtable(f, opts)
