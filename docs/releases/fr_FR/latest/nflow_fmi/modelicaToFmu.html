modelicaToFmu
Compile un modèle Modelica en FMU avec OpenModelica.
📝Syntaxe
fmu = modelicaToFmu(model)
fmu = modelicaToFmu(model, modelName)
fmu = modelicaToFmu(model, modelName, name, value)
📥Arguments d'entrée
Paramètre Description
model une chaîne : le chemin d'un fichier .mo, ou du code source Modelica en ligne.
modelName une chaîne : la classe Modelica à construire. Optionnel ; s'il est omis, c'est le nom de base du fichier .mo (entrée fichier) ou il est analysé depuis la première déclaration model / block / class / package (source en ligne).
name, value paires d'options : 'FmiVersion' ('2.0' par défaut, ou '3.0'), 'FmuType' ('cs' par défaut co-simulation, 'me', ou 'me_cs'), 'Libraries' (une chaîne ou un tableau de cellules de fichiers .mo supplémentaires à charger), 'Rebuild' (false par défaut ; true ignore le cache).
📤Arguments de sortie
Paramètre Description
fmu le chemin du fichier .fmu produit.
📄Description

modelicaToFmu compile un modèle Modelica en unité de maquette fonctionnelle (FMU) à l'aide d'un compilateur OpenModelica installé et renvoie le chemin de la .fmu produite. C'est la moitié « compilation » du pont Modelica de nflow : un bloc modelica l'appelle pour que la FMU résultante soit simulée via le chemin FMI de nflow.

Le résultat est mis en cache dans le répertoire temporaire, indexé par une empreinte de la source, du nom de modèle, de la version d'OpenModelica et des options FMU, de sorte qu'un modèle inchangé n'est compilé qu'une fois.

Pour qu'une variable Modelica devienne un port de sortie exploitable après import, déclarez-la output (par exemple output Real vC;) ; une variable ordinaire est exportée avec la causalité local.

Deux erreurs typées peuvent être levées. Nelson:nflow_fmi:modelicaUnavailable lorsqu'OpenModelica est absent ou incapable d'exporter une FMU (la construction est bloquée) ; vérifiez l'installation avec modelicaInfo et définissez-la avec modelicaConfigure. Nelson:nflow_fmi:modelicaCompileFailed lorsqu'omc s'est exécuté sans produire la FMU ; le message contient les diagnostics d'OpenModelica.

💡Exemples
Compiler un modèle du premier ordre en ligne.
src = sprintf('model FO\n  output Real x(start = 1.0);\nequation\n  der(x) = -x;\nend FO;\n');
fmu = modelicaToFmu(src);
info = fmiInfo(fmu)
Compiler un modèle depuis un fichier .mo.
moFile = [modulepath('nflow_fmi'), '/examples/modelica/RLC.mo'];
fmu = modelicaToFmu(moFile, 'RLC')
