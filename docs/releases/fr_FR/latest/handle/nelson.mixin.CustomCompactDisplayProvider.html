nelson.mixin.CustomCompactDisplayProvider
Fournir un affichage compact d'un objet dans les conteneurs.
📝Syntaxe
classdef MaClasse < nelson.mixin.CustomCompactDisplayProvider
📥Arguments d'entrée
Paramètre Description
obj objet d'une classe derivee de nelson.mixin.CustomCompactDisplayProvider.
config configuration d'affichage utilisee pour la sortie compacte.
width largeur maximale d'affichage.
📤Arguments de sortie
Paramètre Description
rep representation d'affichage compact.
📄Description

Dérivez de nelson.mixin.CustomCompactDisplayProvider pour contrôler l'affichage compact d'un objet lorsqu'il apparaît dans un conteneur tel qu'une cellule ou une structure.

Une sous-classe implémente compactRepresentationForSingleLine(obj, config, width), qui renvoie un objet nelson.display.CompactDisplayRepresentation décrivant l'objet sur une ligne. La représentation est habituellement construite avec la méthode héritée widthConstrainedDataRepresentation(obj, config, width, 'StringArray', texte), qui assemble les données fournies avec le délimiteur défini par config (un nelson.display.DisplayConfiguration) et les tronque avec les points de suspension configurés lorsqu'elles dépassent width caractères. Lorsqu'une instance est affichée dans un conteneur tel qu'une cellule, un champ de structure ou une colonne de table, le texte obtenu est utilisé à la place du [1x1 ClassName] par défaut.

Une méthode compagnon compactRepresentationForColumn(obj, config, width) peut être implémentée pour les dispositions en colonne, et fullDataRepresentation(obj, config, ...) construit une représentation sans contrainte de largeur. Lorsque ces méthodes ne sont pas surchargées, la représentation par défaut est utilisée.

💡Exemples
Une température affichée de façon compacte dans une cellule.
classdef Temp < nelson.mixin.CustomCompactDisplayProvider
  properties
    Celsius = 0
  end
  methods
    function obj = Temp(c)
      if nargin > 0
        obj.Celsius = c;
      end
    end
    function rep = compactRepresentationForSingleLine(obj, config, width)
      txt = [num2str(obj.Celsius), ' degC'];
      rep = widthConstrainedDataRepresentation(obj, config, width, 'StringArray', string(txt));
    end
  end
end
c = {Temp(20), Temp(37)}   % affiche {20 degC}  {37 degC}
