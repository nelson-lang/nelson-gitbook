NFlow.addlibrarypath
Ajoute un répertoire de recherche de bibliothèques de blocs nflow.
📝Syntaxe
NFlow.addlibrarypath(folder)
paths = NFlow.addlibrarypath(folder)
📥Arguments d'entrée
Paramètre Description
folder un répertoire contenant un ou plusieurs sous-dossiers de bibliothèque, chacun avec un library.json et sa bibliothèque native.
📤Arguments de sortie
Paramètre Description
paths la liste mise à jour des répertoires de recherche, un tableau de cellules de chaînes de caractères.
📄Description

NFlow.addlibrarypath ajoute folder aux répertoires de recherche de bibliothèques de blocs nflow et le parcourt. Chaque sous-dossier contenant un library.json à côté de sa bibliothèque native est chargé, de sorte que ses blocs deviennent disponibles pour sim, la génération de code et l'éditeur sans redémarrer Nelson.

Ajouter un répertoire déjà enregistré n'a aucun effet. Une erreur est levée lorsque folder n'existe pas.

💡Exemples
Compile le plugin d'exemple cumprod et enregistre son dossier de bibliothèques.
run([modulepath('nflow_gui'), '/examples/libraries/cumprod/builder.m']);
NFlow.addlibrarypath([modulepath('nflow_gui'), '/examples/libraries']);
NFlow.librarypaths()
