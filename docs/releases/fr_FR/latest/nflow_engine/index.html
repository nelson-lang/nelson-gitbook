moteur nflow

Création et édition programmatiques de modèles de blocs-diagrammes nflow.

NFlow est actuellement publié en version 1.0.0-beta.1 : fonctionnel et testé, mais les détails de ses interfaces et de son format de fichier peuvent encore évoluer selon les retours.

  • NFlow.exportfmu
    Exporte un modele nflow en FMU source FMI 3.0 Co-Simulation.
  • NFlow.plotScopes
    Ouvre une figure par scope d'un résultat de simulation nflow.
  • add_block
    Ajoute un bloc à un modèle nflow depuis une source de bibliothèque.
  • add_line
    Connecte deux ports de blocs dans un modèle nflow.
  • bdIsDirty
    Retourne vrai lorsqu'un modèle nflow a des modifications non sauvegardées.
  • bdIsLoaded
    Retourne vrai lorsqu'un modèle nflow est chargé.
  • bdclose
    Décharge un ou tous les modèles nflow en abandonnant les modifications non sauvegardées.
  • bdroot
    Renvoie le modèle de plus haut niveau d'un chemin de bloc.
  • close_system
    Décharge un modèle nflow ; un modèle modifié requiert un indicateur de sauvegarde explicite.
  • delete_block
    Supprime un bloc et toutes ses connexions d'un modèle nflow.
  • delete_line
    Supprime une connexion entre deux ports de blocs.
  • find_system
    Liste les blocs d'un modèle, éventuellement filtrés par type.
  • gcbh
    Renvoie le handle du bloc courant.
  • getSimulinkBlockHandle
    Renvoie le handle d'un bloc par chemin, ou -1 si introuvable.
  • get_param
    Interroge un paramètre de modèle ou de bloc.
  • getfullname
    Renvoie le chemin complet d'un bloc ou d'un modèle depuis son handle.
  • linmod
    Linéarisation numérique d'un modèle nflow.
  • load_system
    Charge un modèle nflow depuis un fichier .nflow sans ouvrir l'éditeur.
  • new_system
    Crée et charge un modèle nflow vide.
  • nflow_codegenerate
    Genere du code C ou Rust autonome depuis un modele nflow.
  • save_system
    Sauvegarde un modèle nflow dans un fichier .nflow.
  • set_param
    Définit atomiquement des paramètres de modèle ou de bloc.
  • sim
    Simule un modèle nflow et retourne ses résultats.
  • NFlow.sspInfo
    Inspecte, importe et exporte des archives SSP (System Structure and Parameterization).
  • trim
    Trouver un point de fonctionnement d'équilibre d'un modèle nflow.
