ThermalResistor
Resistance thermique : Q_flow = (T_a - T_b) / R.
📝Syntaxe
Type de bloc : ThermalResistor
📥Arguments d'entrée
Paramètre Description
broches physiques 2 broche(s) physique(s) non orientee(s) ; 0 entree(s) de signal.
📤Arguments de sortie
Paramètre Description
ports de signal 0 sortie(s) de signal (lectures de capteur).
📄Description

Composant acausal (Thermique (acausal)). Resistance thermique : Q_flow = (T_a - T_b) / R.

Module nflow_blocks
Bibliotheque Thermique (acausal)
Type ThermalResistor
Libelle ThermalResistor
Solveur Abaisse vers physicalIsland. Solveur de reference dae (differentiel-algebrique) ; la boucle a pas fixe et les solveurs explicites natifs (ode1/ode4/ode45) sont egalement pris en charge (un ilot multicorps articule necessite dae).
