rat
Approximation par une fraction rationnelle.
📝Syntaxe
[N, D] = rat(X)
[N, D] = rat(X, tol)
S = rat(X)
S = rat(X, tol)
📥Arguments d'entrée
Paramètre Description
X Tableau d'entrée : réel ou complexe, scalaire, vecteur ou matrice (single ou double).
tol Tolérance : scalaire. La valeur par défaut est 1e-6 * norm(X(:), 1).
📤Arguments de sortie
Paramètre Description
N Numérateur : tableau de même taille que X, ou le tableau de caractères de la fraction continue lorsqu'une seule sortie est demandée.
D Dénominateur : tableau de même taille que X.
📄Description

[N, D] = rat(X) renvoie deux tableaux d'entiers tels que N ./ D soit proche de X au sens où abs(N ./ D - X) <= tol.

Les approximations rationnelles sont obtenues en tronquant des développements en fraction continue.

S = rat(X) renvoie la représentation en fraction continue sous forme d'un tableau de caractères.

💡Exemples
[N, D] = rat(pi)
S = rat(pi)
