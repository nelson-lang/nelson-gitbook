mcpserver
Demarre le serveur MCP Nelson sur l'entree et la sortie standard.
📝Syntaxe
mcpserver()
mcpserver('--nelson-display-mode=gui')
📄Description

mcpserver demarre un serveur MCP stdio exposant des outils adaptes a Nelson.

Le transport utilise l'entree standard et la sortie standard. Les messages JSON-RPC MCP sont les seules donnees ecrites sur la sortie standard; les diagnostics vont sur l'erreur standard.

Le mode d'affichage par defaut est adv-cli. Il permet les commandes graphiques utilisees par create_nelson_plot tout en conservant le transport MCP sur la sortie standard. Le mode cli est reserve au texte. Le mode gui indique qu'une session graphique visible est souhaitee, avec un serveur toujours lance par nelson-adv-cli.

Les outils exposes sont detect_nelson_modules, check_nelson_code, lint_nelson_code, check_nelson_format, evaluate_nelson_code, run_nelson_file, run_nelson_test_file, format_nelson_file, get_nelson_help, find_nelson_symbol, get_nelson_function_info, get_nelson_workspace, get_nelson_version et create_nelson_plot.

Les outils bases sur des fichiers resolvent les chemins relatifs depuis la racine de workspace configuree et refusent les chemins hors de cette racine. La racine par defaut est nelsonroot.

Les appels d'outils retournent a la fois un contenu texte et un contenu structure avec les champs success, output, error, image et duration.

Les champs longs output et error sont limites par --max-output-characters. Le contenu structure inclut les indicateurs output_truncated et error_truncated.

Certains outils retournent aussi des metadonnees typees dans le champ structure data, par exemple les modules, les compteurs de tests, les informations de version et les metadonnees PNG.

Le serveur expose aussi des ressources locales en lecture seule sous guidelines:// et des prompts reutilisables comme nelson-code-review, nelson-test-author et nelson-plot-agent.

Ollama peut fournir le modele local pour un agent compatible MCP. Dans cette configuration, Ollama execute le modele, l'agent parle MCP, et mcpserver expose les outils Nelson a l'agent.

Le transport JSON-RPC valide la version de protocole 2.0, refuse les requetes invalides et accepte les requetes par lots.

Les options serveur peuvent etre passees comme chaines: --initial-working-folder=CHEMIN, --workspace-root=CHEMIN, --max-output-characters=N, --initialize-nelson-on-startup=true|false, --nelson-display-mode=cli|adv-cli|gui, --allow-execution=true|false, --allow-format=true|false, --log-folder=CHEMIN et --log-level=error|warn|info|debug.

💡Exemples
Declarer Nelson dans Codex.
codex mcp add nelson -- nelson-adv-cli --quiet --noipc --nouserstartup --nousermodules -e "mcpserver"
Declarer Nelson avec le mode graphique visible.
codex mcp add nelson -- nelson-adv-cli --quiet --noipc --nouserstartup --nousermodules -e "mcpserver('--nelson-display-mode=gui')"
Utiliser Nelson MCP avec un agent base sur Ollama.
# Terminal 1: demarrer Ollama et verifier qu'un modele est disponible.
ollama serve
ollama pull llama3.2

# Terminal 2: configurer l'agent compatible MCP avec:
#   fournisseur modele: Ollama
#   endpoint modele: http://127.0.0.1:11434
#   nom du modele: llama3.2
#   nom du serveur MCP: nelson
#   commande du serveur MCP:
nelson-adv-cli --quiet --noipc --nouserstartup --nousermodules -e "mcpserver('--workspace-root=D:/work/nelson-project --nelson-display-mode=adv-cli --max-output-characters=200000')"
Configuration MCP generique de style JSON pour un agent base sur Ollama.
{
  "model": {
    "provider": "ollama",
    "baseUrl": "http://127.0.0.1:11434",
    "name": "llama3.2"
  },
  "mcpServers": {
    "nelson": {
      "command": "nelson-adv-cli",
      "args": [
        "--quiet",
        "--noipc",
        "--nouserstartup",
        "--nousermodules",
        "-e",
        "mcpserver('--workspace-root=D:/work/nelson-project --nelson-display-mode=adv-cli --allow-execution=true --allow-format=true')"
      ]
    }
  }
}
Prompt a donner a un agent Ollama avec outils Nelson.
Utilise le serveur MCP Nelson.
Appelle d'abord get_nelson_workspace.
Appelle ensuite get_nelson_help pour "plot".
Cree et execute un script Nelson qui trace sin(0:0.1:10).
Retourne le chemin PNG produit par create_nelson_plot et resume la sortie Nelson.
