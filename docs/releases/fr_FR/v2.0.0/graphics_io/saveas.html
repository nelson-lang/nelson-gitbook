saveas
Enregistre une figure dans un format de fichier spécifique.
📝Syntaxe
saveas(fig, filename)
saveas(fig, filename, formattype)
📥Arguments d'entrée
Paramètre Description
fig objet figure.
filename vecteur de caractères ou chaîne scalaire : nom de fichier de destination.
formattype vecteur de caractères ou chaîne scalaire : extension ou type de format.
📄Description

saveas enregistre la figure dans un format de fichier spécifique.

Le formattype explicite est prioritaire sur l'extension du fichier. Sans extension, PNG est sélectionné et .png est ajouté. Les modes bureau, web et headless utilisent le même moteur de rendu et le même registre de formats.

Fond : tant que la propriété InvertHardcopy de la figure vaut 'on' (valeur par défaut), le fond exporté est blanc quelle que soit la couleur Color affichée (gris clair par défaut). Passer InvertHardcopy à 'off' pour exporter la couleur de fond affichée.

Les formats vectoriels utilisent des exporteurs de figure dédiés :

Option Format Extension
svg Scalable Vector Graphics .svg
pdf Portable Document Format, page entière en couleur .pdf

Les formats raster sont encodés par le même registre que imwrite :

Option canonique Alias Extension
png - .png
jpg jpeg, jfif .jpg, .jpeg, .jfif
gif - .gif
webp - .webp
tiff tif .tiff, .tif
bmp dib .bmp, .dib
tga - .tga
pbm, pgm, ppm, pnm - .pbm, .pgm, .ppm, .pnm
pcx - .pcx
💡Exemples
x = -2:0.25:2;
y = x;
[X,Y] = meshgrid(x);
F = X.*exp(-X.^2-Y.^2);
surf(X,Y,F);
saveas(gcf(), [tempdir, 'svg-file.svg']);
saveas(gcf(), [tempdir, 'webp-file.webp']);
saveas(gcf(), [tempdir, 'bitmap-file.bmp']);
saveas(gcf(), [tempdir, 'document-file.pdf']);
close(gcf());
