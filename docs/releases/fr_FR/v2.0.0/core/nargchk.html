nargchk
Valide le nombre d'arguments d'entrée.
📝Syntaxe
msg = nargchk(minArgs, maxArgs, n)
msg = nargchk(minArgs, maxArgs, n, 'string')
msgstruct = nargchk(minArgs, maxArgs, n, 'struct')
📥Arguments d'entrée
Paramètre Description
minArgs nombre minimum d'entrées acceptées (valeur entière scalaire).
maxArgs nombre maximum d'entrées acceptées (valeur entière scalaire).
n nombre d'entrées fournies à vérifier, généralement nargin (valeur entière scalaire).
'string' ou 'struct' type de sortie : 'string' (par défaut) renvoie un message de caractères, 'struct' renvoie une structure d'erreur.
📤Arguments de sortie
Paramètre Description
msg un vecteur ligne de caractères contenant le message d'erreur, ou '' (vide) si n est dans l'intervalle [minArgs, maxArgs].
msgstruct une structure avec les champs message et identifier (une structure vide 1x0 si n est dans l'intervalle).
📄Description

nargchk vérifie si le nombre d'arguments d'entrée n est dans l'intervalle [minArgs, maxArgs].

Il renvoie le message 'Not enough input arguments.' lorsque n est inférieur à minArgs, 'Too many input arguments.' lorsque n est supérieur à maxArgs, et un résultat vide sinon.

Il est généralement utilisé sous la forme error(nargchk(minArgs, maxArgs, nargin)) au début d'une fonction.

nargchk est obsolète et conservé pour la compatibilité avec le code existant. Utilisez plutôt narginchk dans le nouveau code.

💡Exemples
Pas assez d'arguments d'entrée :
msg = nargchk(2, 3, 1)
Trop d'arguments d'entrée :
msg = nargchk(1, 2, 3)
Dans l'intervalle, renvoie un message vide :
msg = nargchk(1, 3, 2)
