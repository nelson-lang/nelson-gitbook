gpuArray
Copie un tableau vers le périphérique GPU.
📝Syntaxe
G = gpuArray(A)
📥Arguments d'entrée
Paramètre Description
A un tableau numérique réel, logique, complexe ou entier de petite taille.
📤Arguments de sortie
Paramètre Description
G un gpuArray stocké sur le périphérique.
📄Description

G = gpuArray(A) copie le tableau A vers le GPU et renvoie un objet gpuArray. Les opérations sur G s'exécutent sur le périphérique ; utilisez gather pour ramener le résultat vers l'hôte.

Le périphérique stocke les données en simple précision : une entrée double est convertie en single. Les entrées réelles, logical et complexes sont prises en charge ; les entrées creuses ne le sont pas.

Les petites classes entières int8, uint8, int16 et uint16 sont préservées : leurs valeurs sont exactes en simple précision, l'arithmétique sature à l'intervalle de la classe et gather renvoie la classe d'origine.

int32 et uint32 sont également préservées (stockées sous forme de bits entiers 32 bits bruts) : l'aller-retour, les opérations saturantes +, -, .*, ./, .\, le moins unaire, abs, max/min (élément par élément et réductions), sum, prod, mean, cumsum, cumprod, sort, find, la puissance entière (.^ avec un exposant non négatif), les opérateurs relationnels et les opérations de remise en forme / d'indexation sont pris en charge. Les opérations sans signification entière (les fonctions mathématiques transcendantes élément par élément) déclenchent une erreur claire. Les classes entières 64 bits ne sont pas prises en charge.

Un GPU compatible est requis (voir canUseGPU).

Un tableau du périphérique peut aussi être créé directement avec zeros(sz, 'gpuArray') / ones(sz, 'gpuArray'), ou avec la forme 'like' zeros(sz, 'like', G) où G est un gpuArray.

💡Exemples
A = single(rand(1000));
G = gpuArray(A);
R = gather(G .* G + sqrt(G));
class(G)
