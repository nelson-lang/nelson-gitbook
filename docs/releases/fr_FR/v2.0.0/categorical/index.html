Tableaux categoriels

Le module Categorical fournit des tableaux dont les elements appartiennent a un ensemble fixe de categories textuelles.

  • addcats
    Ajouter des categories a un tableau categoriel.
  • categorical
    Créer un tableau catégoriel.
  • categories
    Lister les categories d'un tableau categoriel.
  • combinations
    Generer toutes les combinaisons de valeurs.
  • countcats
    Compter les elements categoriels par categorie.
  • histcounts
    Compter les valeurs categorielles pour des resumes de type histogramme.
  • iscategorical
    Determiner si un tableau est categoriel.
  • iscategory
    Determiner si des noms sont des categories.
  • isordinal
    Determiner si un tableau categoriel est ordinal.
  • isprotected
    Determiner si un tableau categoriel est protege.
  • isundefined
    Trouver les elements categoriels non definis.
  • mergecats
    Fusionner des categories dans un tableau categoriel.
  • removecats
    Supprimer des categories d'un tableau categoriel.
  • renamecats
    Renommer les categories d'un tableau categoriel.
  • reordercats
    Reordonner les categories d'un tableau categoriel.
  • setcats
    Definir la liste des categories d'un tableau categoriel.
