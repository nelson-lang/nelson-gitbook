notebook
Exécute un document Notebook.
📝Syntaxe
notebook(filename)
tf = notebook(filename)
📥Arguments d'entrée
Paramètre Description
filename un vecteur de caractères ou une chaîne scalaire : un document Notebook (.nlx) ou un fichier Notebook au format texte (.m).
📤Arguments de sortie
Paramètre Description
tf un logique : true si le document a été exécuté.
📄Description

notebook exécute un document Notebook sans l'éditeur : il lit le code de chaque cellule, dans l'ordre, et l'évalue dans l'espace de travail de base. Les variables créées dans une cellule sont visibles dans la suivante, comme lors de l'exécution du document dans l'éditeur.

Le conteneur natif .nlx (un zip contenant le document) et le format texte .m sont pris en charge ; un script .m ordinaire est exécuté comme une seule cellule.

💡Exemples
% construit un document Notebook (.nlx) minimal et l'exécute
d = [tempdir(), createGUID()];
mkdir(d);
fw = fopen([d, '/document.json'], 'wt');
fwrite(fw, '{"blocks":[{"type":"codecell","props":{"code":"a = 40 + 2;"}}]}');
fclose(fw);
nlx = [tempdir(), createGUID(), '.nlx'];
odir = pwd();
cd(d);
zip(nlx, 'document.json');
cd(odir);
notebook(nlx);
