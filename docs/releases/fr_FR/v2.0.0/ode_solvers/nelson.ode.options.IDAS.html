nelson.ode.options.IDAS
Objet d'options pour le solveur IDAS BDF optionnel.
📝Syntaxe
options = nelson.ode.options.IDAS()
options = nelson.ode.options.IDAS(nom, valeur)
📄Description

nelson.ode.options.IDAS cree un objet d'options pour la valeur de solveur 'idas' utilisee par le workflow objet ode.

Groupe d'options Noms Role
Pas et tolerances InitialStep, MaxStep, MinStep, RelTol, AbsTol, MaxOrder Controle l'integration BDF adaptative pour equations residuelles.
Conditions initiales ComputeConsistentInitialConditions Demande des y0 et yp0 coherents pour les problemes totalement implicites.
Algebre lineaire LinearSolver, Preconditioner, Jacobian, JPattern Donne la structure du systeme residuel et les indications de preconditionnement.
Disponibilite 'idas' Utilise le backend totalement implicite optionnel quand il est compile et active.

Cette valeur de solveur est disponible uniquement quand Nelson est construit avec le backend optionnel SUNDIALS. Elle utilise IDAS avec la methode BDF pour les problemes residuels totalement implicites F(t,y,yp)=0.

Les options prises en charge incluent InitialStep, MaxStep, MinStep, RelTol, AbsTol, Refine, NormControl, OutputFcn, OutputSelection, Vectorization, MaxOrder, ComputeConsistentInitialConditions, LinearSolver et Preconditioner. OutputFcn est appelee sur les points de sortie retournes par le backend. LinearSolver accepte les valeurs SUNDIALS denses, iteratives et directes creuses optionnelles quand la bibliotheque correspondante est disponible. Preconditioner accepte 'auto', 'none', 'jacobi', 'banded' ou 'ilu0'. Avec un JPattern creux, 'ilu0' construit un preconditionneur LU incomplet creux compact sans workspace dense.

💡Exemples
Creer un probleme residuel IDAS.
options = nelson.ode.options.IDAS();
problem = ode('EquationType', 'fullyimplicit', ...
  'ODEFcn', @(t,y,yp) yp + y, ...
  'InitialValue', 1, ...
  'InitialSlope', -1, ...
  'SolverOptions', options);
result = solve(problem, 0, 1)
