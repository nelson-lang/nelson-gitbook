lasso
Regularisation lasso et elastic net pour modeles lineaires.
📝Syntaxe
B = lasso(X, y)
B = lasso(X, y, Name, Value)
[B, FitInfo] = lasso(...)
📄Description

lasso ajuste des modeles lineaires regularises L1 et elastic-net par descente de coordonnees.

Les options nom-valeur prises en charge sont Alpha, Lambda, LambdaRatio, NumLambda, Standardize, Intercept, MaxIter, RelTol et Weights.

💡Exemples
X = randn(100, 5);
y = X * [0; 2; 0; -3; 0] + 0.1 * randn(100, 1);
[B, FitInfo] = lasso(X, y, 'NumLambda', 10)
