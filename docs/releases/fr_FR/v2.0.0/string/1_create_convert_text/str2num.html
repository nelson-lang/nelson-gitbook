str2num
Convertit un tableau de caractères en tableau numérique.
📝Syntaxe
x = str2num(s)
[x, ok] = str2num(s)
📥Arguments d'entrée
Paramètre Description
s un vecteur de caractères ou une chaîne scalaire contenant une expression numérique.
📤Arguments de sortie
Paramètre Description
x le résultat numérique, ou [] si le texte ne peut être évalué en nombre.
ok un logique : true si la conversion a réussi.
📄Description

x = str2num(s) convertit le tableau de caractères s en tableau numérique en l'évaluant.

Comme str2num évalue son entrée, préférez str2double pour les conversions scalaires simples.

💡Exemples
x = str2num('[1 2 3]')
[y, ok] = str2num('4 5; 6 7')
