animatedline
Creer une ligne animee.
📝Syntaxe
an = animatedline()
an = animatedline(x, y)
an = animatedline(x, y, z)
an = animatedline(ax, ...)
an = animatedline(..., propertyName, propertyValue)
📥Arguments d'entrée
Paramètre Description
x, y, z coordonnees numeriques: scalaires ou tableaux avec le meme nombre d'elements.
ax axes cible ou objet groupe.
propertyName chaine scalaire ou vecteur de caracteres.
propertyValue valeur de propriete.
📤Arguments de sortie
Paramètre Description
an objet graphique de type animatedline.
📄Description

animatedline cree une ligne animee sans point stocke.

animatedline(x, y) cree une ligne animee initialisee avec des coordonnees deux dimensions.

animatedline(x, y, z) cree une ligne animee initialisee avec des coordonnees trois dimensions.

Utilisez addpoints, clearpoints et getpoints pour modifier ou lire les coordonnees stockees.

MaximumNumPoints limite le nombre de points stockes et conserve les points les plus recents.

Voir proprietes de animatedline pour la liste complete des proprietes.

💡Exemples
f = figure();
ax = axes('Parent', f);
an = animatedline(ax, 'Color', [0 0.4 0.8], 'LineWidth', 2);
x = linspace(0, 2*pi, 120);
addpoints(an, x, sin(x));
