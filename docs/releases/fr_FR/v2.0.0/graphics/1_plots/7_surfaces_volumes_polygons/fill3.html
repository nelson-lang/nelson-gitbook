fill3
Creer des patchs 3-D remplis.
📝Syntaxe
fill3(X, Y, Z, C)
fill3(X1, Y1, Z1, C1, ..., Xn, Yn, Zn, Cn)
fill3(..., propertyName, propertyValue)
fill3(ax, ...)
go = fill3(...)
📥Arguments d'entrée
Paramètre Description
X Coordonnees x : vecteur ou matrice.
Y Coordonnees y : vecteur ou matrice.
Z Coordonnees z : vecteur ou matrice.
C Donnees de couleur ou specification de couleur.
📤Arguments de sortie
Paramètre Description
go Handles graphiques de type patch.
📄Description

fill3 cree des polygones remplis en coordonnees 3-D. Chaque groupe d'entrees cree un ou plusieurs objets patch et accepte les proprietes nom-valeur de patch.

💡Exemples
x = [0 1 0];
y = [0 0 1];
z = [0 1 0];
fill3(x, y, z, 'red');
view(3)
