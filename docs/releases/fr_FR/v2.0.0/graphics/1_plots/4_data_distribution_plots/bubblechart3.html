bubblechart3
Afficher un graphique a bulles 3-D.
📝Syntaxe
bubblechart3(x, y, z, sz)
bubblechart3(x, y, z, sz, c)
bubblechart3(tbl, xvar, yvar, zvar, szvar)
bubblechart3(tbl, xvar, yvar, zvar, szvar, cvar)
bubblechart3(parent, ...)
bubblechart3(..., propertyName, propertyValue)
h = bubblechart3(...)
📄Description

bubblechart3 affiche un nuage de points 3-D dont les tailles de marqueurs sont controlees par sz.

c specifie les couleurs des bulles. Il peut s'agir d'un nom de couleur, d'un nom court, d'un triplet RGB, d'un vecteur de couleurs ou d'une matrice RGB.

L'entree table selectionne les donnees depuis les variables de tbl. Chaque selecteur peut etre un nom de variable, une string, un indice, un selecteur logique, ou un vecteur cellule/string de noms. Plusieurs variables selectionnees creent plusieurs objets bubblechart.

Le handle retourne est un objet bubblechart avec XData, YData, ZData et SizeData.

Voir proprietes de bubblechart pour la liste complete des proprietes.

💡Exemples
Afficher un graphique a bulles 3-D.
t = 0:0.4:2*pi;
bubblechart3(cos(t), sin(t), t, 30 + 20 * t, 'b');
Creer un graphique a bulles 3-D depuis une table.
t = table((1:4)', [4; 2; 6; 3], [7; 8; 9; 10], [20; 60; 30; 80], [1; 2; 3; 4], ...
  'VariableNames', {'x', 'y', 'z', 's', 'c'});
h = bubblechart3(t, 'x', 'y', 'z', 's', 'c');
