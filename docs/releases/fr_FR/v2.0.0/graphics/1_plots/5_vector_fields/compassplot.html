compassplot
Affiche des vecteurs depuis l'origine en coordonnees polaires.
📝Syntaxe
compassplot(z)
compassplot(theta, r)
compassplot(parent, ...)
h = compassplot(...)
📄Description

compassplot affiche des valeurs complexes ou des paires de coordonnees polaires sous forme de fleches partant de l'origine. Le handle retourne est un objet compassplot.

La page proprietes de compassplot liste les proprietes d'objet prises en charge.

💡Exemples
Afficher des vecteurs complexes.
z = [1 + 1i, 1 - 1i, -1 + 0.5i];
compassplot(z);
