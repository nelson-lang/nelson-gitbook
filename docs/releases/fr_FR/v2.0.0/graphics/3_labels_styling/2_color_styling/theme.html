theme
Definit le theme de couleur d'une figure.
📝Syntaxe
theme(themename)
theme(f, themename)
theme(f, t)
t = theme(...)
📥Arguments d'entrée
Paramètre Description
themename une chaine : 'light' ou 'dark'.
f un objet graphique. Figure cible. Si un objet non figure est fourni, sa figure ancetre est utilisee. Si omis, la figure courante est utilisee.
t un objet theme, tel que renvoye par la propriete Theme d'une figure.
📤Arguments de sortie
Paramètre Description
t l'objet theme applique a la figure.
📄Description

theme definit le theme de couleur d'une figure a 'light' ou 'dark'.

L'application d'un theme met a jour la propriete Theme de la figure ainsi que les couleurs de la figure et de ses enfants qui utilisent des couleurs gerees par le theme.

Sans argument figure, le theme est applique a la figure courante renvoyee par gcf.

💡Exemples
Appliquer un theme sombre a une figure.
f = figure();
surf(peaks);
theme(f, 'dark');
Interroger le theme applique a la figure courante.
f = figure();
t = theme('light')
