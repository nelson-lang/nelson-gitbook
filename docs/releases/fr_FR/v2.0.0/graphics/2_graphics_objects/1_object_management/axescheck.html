axescheck
Extrait un handle d'axes d'une liste d'arguments.
📝Syntaxe
[ax, args, nargs] = axescheck(arg1, arg2, ...)
📥Arguments d'entrée
Paramètre Description
arg1, arg2, ... une liste d'arguments, telle que passée à une fonction de tracé.
📤Arguments de sortie
Paramètre Description
ax le handle d'axes trouvé dans la liste, ou [] si aucun n'a été fourni.
args les arguments restants, sous forme de tableau de cellules.
nargs le nombre d'arguments restants, numel(args).
📄Description

axescheck est un utilitaire pour les fonctions de tracé. Il renvoie dans ax un handle d'axes de tête (ou [] lorsque le premier argument n'est pas un axes), les arguments restants étant dans args. Une paire 'Parent', valeur présente dans la liste fournit également l'axes et est retirée de args.

💡Exemples
ax = axes();
[cax, args, nargs] = axescheck(ax, 1, 2)
