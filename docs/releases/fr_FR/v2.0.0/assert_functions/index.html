Fonctions d'assertion

Le module assert_functions fournit des assertions pour les tests unitaires, les contrats d'execution et les diagnostics.

Toutes les assertions partagent le meme contrat : sans sortie elles levent une erreur en cas d'echec ; avec sorties elles retournent [res, msg].

L'API canonique utilise des noms d'assertion qualifies, par exemple asserts.isequal, asserts.warning et asserts.satisfies.

    Verifie qu'une condition est vraie.

    Nom historique de asserts.istrue.
  • asserts.allfalse
    Verifie que chaque entree logique vaut false.
  • asserts.alltrue
    Verifie que chaque entree logique vaut true.
  • asserts.checkerror
    Verifie qu'une commande leve une erreur attendue.
  • asserts.class
    Verifie qu'une valeur a la classe attendue.
  • asserts.columnVector
    Verifie qu'une valeur est un vecteur colonne.
  • asserts.columns
    Verifie le nombre de colonnes.
  • asserts.contains
    Verifie qu'un texte contient un motif.
  • asserts.containsAll
    Verifie qu'un texte contient tous les motifs attendus.
  • asserts.containsAny
    Verifie qu'un texte contient au moins un motif attendu.
  • asserts.diff
    Retourne les diagnostics d'egalite sans lever d'erreur.
  • asserts.empty

  • asserts.endsWith
    Verifie qu'un texte se termine par un suffixe.
  • asserts.fail
    Force un echec d'assertion.
  • asserts.fields
    Verifie l'ensemble exact des champs d'une structure.

  • asserts.hasFields
    Verifie qu'une structure possede tous les champs attendus.
  • asserts.inRange
    Verifie que chaque valeur est dans un intervalle inclusif.
  • asserts.isapprox
    Verifie que les valeurs numeriques calculee et attendue sont approximativement egales.
  • asserts.isequal
    Verifie que les valeurs calculee et attendue sont egales.
  • asserts.isfalse

  • asserts.istrue

  • asserts.length
    Verifie la longueur d'une valeur.

  • asserts.matchesAny
    Verifie qu'un texte correspond a au moins une expression reguliere.

  • asserts.noError

  • asserts.size
