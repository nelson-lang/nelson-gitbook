delete
Supprime des objets handle ou des fichiers.
📝Syntaxe
delete(h)
delete filename
delete(filename)
delete(filename1, ..., filenameN)
delete(filenames)
📥Arguments d'entrée
Paramètre Description
h un objet handle : scalaire ou matrice.
filename un vecteur de caracteres ou une chaine scalaire : nom du fichier a supprimer. Le caractere generique * est accepte.
filenames un tableau de chaines ou un tableau de cellules de vecteurs de caracteres : noms des fichiers a supprimer. Chaque element peut contenir le caractere generique *.
📄Description

delete(h) invalide les objets handle references par h et libere leurs ressources natives.

Une fois supprimes, tous les alias vers les memes objets deviennent invalides.

Pour les objets handle classdef, delete appelle la methode destructeur de la classe quand elle existe et notifie ObjectBeingDestroyed avant que l'objet devienne invalide.

Pour les tableaux de handles, chaque element valide est invalide.

Pour supprimer seulement une variable, utilisez la fonction clear. Les autres alias restent valides jusqu'a l'appel a delete.

delete(filename) supprime definitivement le fichier filename du disque. Les dossiers ne sont pas supprimes (voir rmdir).

delete(filenames) supprime plusieurs fichiers donnes sous forme de tableau de chaines ou de tableau de cellules de vecteurs de caracteres. Plusieurs noms de fichiers peuvent aussi etre passes en arguments separes.

Chaque nom de fichier peut contenir le caractere generique *. Quand aucun fichier ne correspond a un nom, un avertissement (identifiant Nelson:FileNotFound) est affiche et les autres fichiers sont tout de meme supprimes.

💡Exemples
Supprimer plusieurs fichiers avec un vecteur de noms de fichiers.
d = tempname();
mkdir(d);
filewrite(fullfile(d, 'a.txt'), 'a');
filewrite(fullfile(d, 'b.txt'), 'b');
filewrite(fullfile(d, 'c.dat'), 'c');
delete({fullfile(d, 'a.txt'), fullfile(d, 'b.txt')});
delete(string(fullfile(d, "*.dat")));
dir(d)
rmdir(d);
Supprimer un tableau de handles classdef.
clear classes
d = [tempdir(), 'nelson_help_delete/'];
mkdir(d);
filewrite([d, '/NelsonHelpDeleteCounter.m'], ["classdef NelsonHelpDeleteCounter < handle"; "  properties"; "    Count = 0"; "  end"; "end"]);
addpath(d);
a = NelsonHelpDeleteCounter();
b = NelsonHelpDeleteCounter();
h = [a, b];
delete(h);
isvalid(a)
isvalid(b)
