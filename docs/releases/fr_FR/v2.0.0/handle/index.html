Handle

Le module Handle fournit des outils pour créer et manipuler des objets handle dans Nelson.

Les objets handle sont des références légères vers des structures de données plus volumineuses, permettant une gestion efficace de la mémoire et le partage de données entre différentes parties d'un programme.

Ce module inclut des fonctions pour créer, copier et détruire des objets handle, ainsi que pour gérer leur durée de vie et garantir un nettoyage approprié.

Il inclut aussi les fonctions de reflection classdef, d'evenements, d'ecouteurs, de proprietes dynamiques, de references faibles et de handles invalides types.

  • addlistener
    Ajoute un callback ecouteur a un evenement classdef.
  • cancel
    Annuler un objet annulable.
  • delete
    Supprime des objets handle ou des fichiers.
  • dynamicprops
    Classe de base pour objets handle avec proprietes dynamiques d'instance.
  • enumeration
    Renvoie les membres d'une classe d'enumeration classdef.
  • events
    Renvoie les noms des evenements d'un objet ou d'une classe classdef.
  • get
    Récupère la valeur d'une propriété d'un objet handle.
  • handle
    Classe de base des objets à sémantique de référence.
  • insert
    Inserer des entrees dans un objet prenant en charge l'insertion par cle.
  • invoke
    Invoque une méthode sur un objet handle.
  • isKey
    Determiner si un objet contient une cle.
  • ismethod
    Renvoie true si une methode publique appartient a un objet ou une classe.
  • isprop
    Renvoie true si une propriete appartient a un objet ou une classe.
  • isvalid
    Retourne vrai pour les handles valides.
  • listener
    Cree un ecouteur d'evenement classdef.
  • lookup
    Rechercher des valeurs dans un objet.
  • metaclass
    Renvoie les metadonnees classdef.
  • methods
    Renvoie les noms des methodes publiques d'un objet ou d'une classe.
  • nelson.lang.HandlePlaceholder
    Classe handle de remplacement pour les cibles absentes.
  • nelson.lang.WeakReference
    Reference faible vers un objet handle.
  • nelson.lang.invalidHandle
    Creer un handle invalide avec une classe handle donnee.
  • nelson.mixin.Copyable
    Ajouter une méthode copy à une classe handle.
  • nelson.mixin.CustomCompactDisplayProvider
    Fournir un affichage compact d'un objet dans les conteneurs.
  • nelson.mixin.CustomDisplay
    Personnaliser l'affichage d'un objet.
  • nelson.mixin.Heterogeneous
    Autoriser des tableaux mélangeant des classes apparentées.
  • nelson.mixin.Scalar
    Restreindre une classe à des instances scalaires.
  • nelson.mixin.SetGet
    Ajouter l'accès aux propriétés par set et get à une classe handle.
  • nelson.mixin.SetGetExactNames
    Accès set et get aux propriétés avec noms sensibles à la casse.
  • notify
    Notifie les ecouteurs d'un evenement classdef.
  • properties
    Renvoie les noms des proprietes publiques d'un objet ou d'une classe.
  • remove
    Supprimer des entrees d'un objet.
  • set
    Définit la valeur d'une propriété d'un objet handle.
  • superclasses
    Noms des superclasses d'une classe.
