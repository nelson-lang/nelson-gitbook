Geometrie

Le module Geometrie fournit des outils pour effectuer des transformations et calculs geometriques dans Nelson.

Il prend en charge les rotations en espace tridimensionnel, les enveloppes convexes, les triangulations de Delaunay, les diagrammes de Voronoi, les recherches spatiales et l'interpolation de donnees dispersees.

Ce module est utile pour l'infographie, la robotique, la geometrie algorithmique, l'interpolation et l'analyse spatiale.

  • alphaShape
    Objet alpha shape
  • boundary
    Facettes frontiere d'un ensemble de points
  • convhull
    Enveloppe convexe de points 2-D ou 3-D
  • convhulln
    Enveloppe convexe en N dimensions
  • delaunay
    Triangulation de Delaunay de points 2-D ou 3-D
  • delaunayTriangulation
    Objet de triangulation de Delaunay
  • delaunayn
    Triangulation de Delaunay en N dimensions
  • dsearchn
    Recherche du point le plus proche
  • griddata
    Interpolation de donnees dispersees
  • rotx
    Matrice de transformation 3x3 pour rotation autour de l'axe x
  • roty
    Matrice de transformation 3x3 pour rotation autour de l'axe y
  • rotz
    Matrice de transformation 3x3 pour rotation autour de l'axe z
  • scatteredInterpolant
    Objet d'interpolation de donnees dispersees
  • stlread
    Creer une triangulation depuis un fichier STL
  • stlwrite
    Creer un fichier STL depuis une triangulation
  • triangulation
    Objet de triangulation
  • tsearchn
    Localisation de point dans une triangulation
  • voronoi
    Diagramme de Voronoi de points plans
  • voronoin
    Diagramme de Voronoi en N dimensions
